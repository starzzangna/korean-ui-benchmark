# 한국형 UI 디자인 · 4군 비교

같은 한국어 과제와 새 콘텐츠로 작성한 **no skill / A / B / 자체 스킬**의 웹 시안 비교입니다. 7개 카테고리, 총28개 시안과 공통 기능 검사, 재사용 가능한 자체 스킬을 포함합니다.

과거 비교 사이트·수정 이력·개인 작업 경로는 포함하지 않습니다. 모든 브랜드·상품·작품·일정은 이 비교를 위한 가상 자료입니다.

## 온라인 비교

**[GitHub Pages에서 4군 비교 페이지 열기](https://starzzangna.github.io/korean-ui-benchmark/)**

설치 없이 7개 카테고리의 **no skill / A / B / 자체 스킬**을 비교할 수 있습니다. 화면에서 4군·2군 보기, 모바일 폭, 카테고리를 선택하고 각 시안의 기능과 모션을 직접 확인하세요. 실제 신청·결제·메일 전송은 하지 않는 로컬 상태 기반 데모입니다.

## 실행

Node.js22 이상과 npm이 필요합니다.

```sh
npm ci
npm run build
npm run dev
```

브라우저에서 `http://127.0.0.1:4300`을 엽니다. 4군 동시 보기, 원하는 2군 나란히 보기, 카테고리·화면 폭·구간 이동을 제공합니다. 프레임 안의 검색·선택·상세·확대·신청을 직접 조작할 수 있습니다.

검사는 다음과 같이 실행합니다.

```sh
npm run check
npx playwright install chromium
npm test
npm run test:branches
```

`npm test`와 `test:branches`는 별도 검사 서버4311을 시작하고 종료합니다. 결과/스크린샷은 Git에서 제외되는 `artifacts/`에 저장됩니다. 이미 실행 중인 서버를 쓰려면 `BASE_URL`, 설치된 Chromium 계열 브라우저를 쓰려면 `CHROME_PATH` 환경 변수를 지정합니다. 기본 검사에는 `QA_GROUP=none|a|b|own`, `QA_TOPIC=brand` 또는 `local,portfolio` 등으로 범위를 좁힐 수 있습니다. 선택지 연결 검사는 모든 필수 값의 대표 결과를 확인합니다.

`npm run build`는 저장된 코드와 데이터로 정적 HTML을 재구성합니다. AI를 다시 호출하거나 새로운 실험을 생성하는 명령은 아닙니다.

## 비교군

| 화면 표기 | 범위 |
|---|---|
| no skill | 별도 스킬 규칙을 지정하지 않은 기본 구성 |
| A | 외부 지침 A의 대상 중심 구성·명료한 조판·원본 모션 모듈을 적용 |
| B | 외부 지침 B의 한국어 조판·비대칭 배치·구간 등장·단일 HTML 출력을 적용 |
| 자체 스킬 | 자료/행동의 관계·구간 연결·정렬·카테고리별 색/모션 기준을 적용 |

하나의 작성자가 전체를 구현했고 **기능 엔진과 데이터는 공통**입니다. 독립 생성·눈가림 실험·통계적 우위의 증명이 아닙니다. no skill도 같은 작성자의 맥락에서 자유롭지 않습니다. 원본 스킬의 모든 규칙/도구를 무수정으로 통과한 인증 결과로 해석하지 않습니다. 적용 범위와 외부 의존성은 [비교 방법](docs/METHOD.md)에 구분했습니다.

## 카테고리와 파일

| 카테고리 | 새 가상 서비스 | 주요 기능 |
|---|---|---|
| SaaS | 태스크링 | 업무 검색/상태·상세 수정·추가 |
| 브랜드 | 도담문구 | 상품 탐색·상세·관심 목록 |
| 로컬 서비스 | 흙결 공방 | 수업 선택·신청 확인·금액 |
| 식당 | 아침정원 | 메뉴 검색/분류·방문 예약 데모 |
| 포트폴리오 | 모서리 스튜디오 | 분야 필터·전체/세부·확대/이동·문의 초안 |
| 전문 서비스 | 정돈실 | 서비스/산출물·문의 선택 연결 |
| 행사 | 재료의 다음 장 | 날짜별 일정·설명 펼침·패스/인원 합계 |

```text
index.html                    비교 화면
src/                          공통 기능·렌더러·4개 디자인 스타일
shared/                       새 데이터·사진·가상 상품/작품·글꼴
results/{none,a,b,own}/        28개 정적 시안
skills/korean-ui-design/      재사용 가능한 자체 스킬
docs/                         과제·방법·출처·이용 조건
reports/                      이번 공개 묶음의 최종 검증 요약
scripts/                      빌드·서버·정적 검사·Playwright 검사
```

자체 스킬은 `skills/korean-ui-design` 폴더와 필요한 참고 자료를 프로젝트에 복사해 `SKILL.md`를 참조할 수 있습니다. 프로젝트에 맞는 카테고리 문서와 `assets/DESIGN.md`를 사용하세요. 비교군의 완성 페이지를 그대로 복사하는 방식과는 구분합니다.

## Git 공개 범위

정적 파일은 하위 경로에서도 동작하도록 상대 경로를 사용합니다. GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시하며 해당 브랜치가 갱신되면 GitHub에서 다시 배포합니다. `.nojekyll`로 정적 자료 경로를 유지하고 `.gitattributes`로 원본/에셋의 해시가 줄바꿈 변환 때문에 바뀌지 않게 했습니다. 저장소의 CI는 빌드·검사를 수행하며, Pages 배포는 GitHub의 브랜치 게시 기능을 사용합니다.

화면 코드를 변경했다면 `npm run build`로 `results/`를 재생성한 뒤 함께 커밋하세요. Pages 게시 설정은 저장소의 **Settings → Pages → Deploy from a branch → main / (root)**입니다.

`node_modules/`, `artifacts/`, 환경 변수 파일, 로컬 입력 캐시/작업 경로는 업로드하지 않습니다. [검증 결과](reports/README.md), [원본 출처](docs/SOURCES.md), [에셋 이용 조건](docs/ASSETS.md)을 함께 읽어주세요. A/B 별칭은 화면 라벨이며 원본 출처를 감추거나 권리를 이전하는 의미가 아닙니다.

신규 코드에는 MIT 라이선스를 적용합니다. 외부 모션 코드·글꼴·사진은 각각의 원래 이용 조건을 따릅니다. 실제 서버·계정·예약·결제·메일 전송은 연결하지 않았습니다.
