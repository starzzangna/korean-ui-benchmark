# 장면 모션과 조작 모션

대표 장면은 브랜드의 리듬·깊이를 표현하고, 조작 모션은 선택과 결과를 알린다. 둘의 거리·시간을 독립적으로 결정한다. 이 문서의 수치는 모션 조정의 시작값이며 웹 표준이나 품질 점수가 아니다.

## 내용의 변화에 붙이는 동작

같은 hover 이동·이미지 확대·회전을 모든 업종에 적용한 뒤 수치만 달리해 고유 모션이라고 설명하지 않는다. 대상이 무엇을 전달하고 무엇이 실제로 바뀌는지부터 정한다. [선택/결과 실행 예제](../assets/selection-feedback.html)는 값을 즉시 갱신하고 새 결과만 강조하며 빠른 재선택·모션 감소를 처리한다.

| 조건 | 실제 변화와 제한된 강조 |
|---|---|
| 업무 상태 변경 | 실제 변한 집계/표식만 짧게 강조. 행의 비교 축은 안정적으로 유지 |
| 상품/분야 색인 | 필터·노출 대상·현재 선택·상세 범위를 즉시 맞추고 도착 자료를 강조 |
| 수업 선택 | 신청 수업/금액과 다음 조작을 연결. 초점 이동은 장식 종료를 기다리지 않음 |
| 음식 사진 | 제목과 음식이 하나의 장면으로 들어오게 하되 읽기를 지연하거나 비조작 사진에 클릭 신호를 만들지 않음 |
| 작품 상세 | 같은 작업의 전체/세부와 캡션을 보존하고 새로 읽힌 이미지·복귀 위치를 짧게 연결 |
| 서비스 선택 | 새 예시/판단만 전환하고 문의 값은 동기 갱신. 목록 전체를 재등장시키지 않음 |
| 날짜 선택 | 해당 프로그램을 즉시 표시하고 새 목록만 짧게 연결. 열린 표식의 끝 상태와 축은 유지 |

모든 구간을 자동 등장시키거나 대표 자료 하나로만 제한하지 않는다. 읽는 흐름이 바뀌는 목록·작품·신청의 묶음도 진입 대상으로 검토한다. 대표 장면과 실제 상태 변화를 구분하고, 프레임/이미지/컨트롤의 변형 레이어를 분리한다. 재선택은 진행 중 효과를 취소해 누적을 막으며 모션 감소 전환 때도 진행 중 효과를 정리한다. 효과가 없어도 내용·선택·초점은 완전해야 한다.

## 화면 목적에 맞는 시간 관계

업무·입력의 컨트롤은 기존 짧은 반응을 유지한다. 표현 중심 소개에서는 [visual-coherence.md](visual-coherence.md)의 프레임·사진 관계를 정한 뒤 `data-km-tempo="flow"`를 해당 영역에 선택 적용할 수 있다. 예제 시작값은 장면820ms, 프레임680ms, 사진760ms, 대표 CTA420ms이며 작은 이동·확대와 긴 감속을 연결한다. 클릭·결과·초점은 즉시 처리한다. 다른 브랜드에 같은 속도·곡선을 강제하지 않는다.

기본 CTA230ms는 모든 화면의 상한이 아니다. 대표 자료의 반응을 생략하고 CTA만 구현한 경우에는 그 선택이 정지 구도와 함께 충분한지 실제 화면에서 확인한다. 시간만 늘리기 전에 주인공의 크기·프레임·여백을 먼저 편집한다.

## 역할별 시작 레시피

| 역할 | calm 시작값 | 계기·끝 상태 |
|---|---|---|
| 대표 사진/작업/포스터 | translateY(18px→0), opacity, 650~850ms | 최초 진입 또는 해당 장면 첫 교차; 한 번 후 정지 |
| 겹친 프레임 | rotate(1~2deg), hover에서0deg, 400~520ms | 인쇄물/작품의 놓임을 표현; 글이나 가격은 회전시키지 않음 |
| 대표 CTA | translateY(-2px), 200~260ms; 화살표는 이동 방향으로 짧게 | 포인터 hover/누름 후 복원; 즉시 동작 |
| 상품/작업 탐색 이미지 | 작은 scale(1.02~1.04) 또는 프레임 이동 | 하나의 방향을 고르고 과도하게 중첩하지 않음 |
| 상세/확인 | translateY(6~12px→0)+opacity, 180~240ms | 열 때 맥락 표시; 초점은 전환 종료를 기다리지 않음 |
| 필터/업무 행/폼 오류 | 즉시 내용 갱신, 필요하면 짧은 색/상태 변화 | 장면 등장 효과를 전파하지 않음 |

신규 브랜드·포트폴리오·행사에서 적합한 주인공이 있고 별도 선호가 없으면 calm 장면 표현부터 검토한다. none은 정보 중심·정적인 브랜드 규칙·사용자 선호에 적합하다. expressive는 더 큰 시각 대비와 연출이 실제 내용을 돕는 경우에만 선택한다. 매 행·모든 섹션·모든 버튼을 움직이는 설정으로 해석하지 않는다. 사용자에게 보일 주인공보다 먼저 주변 장식을 움직이지 않는다.

SCENE_MOTION과 CONTROL_MOTION은 대상별 결정이다. 예를 들어 작업 대표 이미지에는20px/600ms 단회 등장, 작업 필터에는 즉시 변경, 상세에는8px/180ms를 함께 쓸 수 있다. 작은 hover 세 건으로 장면 등장 구현을 대신하지 않는다.

## 실행 가능한 구현

[assets/motion/index.html](../assets/motion/index.html)을 실행하고 [USAGE.md](../assets/motion/USAGE.md)에서 선택한 역할만 복사한다. 공통 색/폰트/사진이나 완성 사이트 레이아웃은 강제하지 않는다. 기존 프로젝트에 모션 체계가 있으면 같은 역할을 기존 구현으로 재현할 수 있다. legacy interactions.css/js와 같은 요소에 중복 연결하지 않는다.

translate 등장 wrapper, rotate 프레임, 이미지 자체의 확대를 분리한다. CSS transform을 한 요소에 여러 규칙으로 덮어쓰지 않는다. 태블릿에서 기울어진 바깥 경계가 문서를 넓히지 않는지 본다. 크롭 wrapper는 장식/이미지 경계용이며 본문·키보드 링·확대 상세를 잘라 문제를 숨기지 않는다.

HTML/CSS 기본 상태는 콘텐츠가 보이는 상태다. JS가 준비된 경우에만 안전한 단회 등장 상태를 적용하고, JS 오류·IO 미지원·스크롤 복원에서 보이지 않는 내용이 남지 않게 한다. 첫 핵심 정보나 CTA의 조작을 모션 완료까지 미루지 않는다. 전역 transition:all, 스크롤 가로채기, 기본 무한 float는 추가하지 않는다.

소개형 페이지에서 구간의 읽는 순서를 돕는 경우 첫 제목·소개 문단과 새 구간의 제목/설명을 단회 등장시킨다. 시작값은 translateY 12~16px·opacity 0.65→1·약 600ms의 감속이며 같은 문구 묶음의 지연은 50~60ms, 총 120ms 이내로 제한한다. 섹션 전체나 폼을 한 덩어리로 숨기지 않고, 가격·필터 결과·오류·주요 버튼은 즉시 조작 가능하게 둔다. JS/IntersectionObserver 미지원 시 기본 내용이 보이고, 모션 감소 설정을 실행 중 변경해도 진행 중 애니메이션을 취소해 원래 위치로 복원한다. 키보드로 진입한 내용은 이동하지 않는다.

prefers-reduced-motion에서는 이동·회전 전환·scale·fade를 제거/축소하고 콘텐츠를 즉시 보인다. 런타임 설정 변경도 고려한다. 터치에서 hover는 장식이며 상세/선택은 tap으로 동일하게 가능해야 한다. 키보드 초점과 상태는 모션 없이도 읽힌다.

## 실제 크기 검토

대표 장면의 처음/중간/종료를 실제 크기로 보고 좌표·시간·사용 목적을 확인한다. 작은 프리뷰 축소율을 보상하려고 제품 자체 이동을 과장하지 않는다. 320/390/768/1440과 글자200%에서 회전/등장 중에도 내용 손실을 확인한다. 모션 개수·computed transform만으로 고급스러움을 판정하지 않는다.

## 부드러운 시작과 감속

개별 프레임 스타일의 transition 축약 선언이 모션 모듈의 transform 전환을 덮어쓰지 않는지 확인한다. 최종 자세 변화만 보지 말고 중간 프레임과 pointer 왕복의 연속성을 검사한다. 그림자만 바꿀 목적의 선언이라면 전체 transition 목록을 지우지 않도록 한다.

부드러운 움직임을 원하면 거리부터 키우지 않고 시작·끝 속도와 전환 시간을 함께 조정한다. 예제의 장면/프레임은 cubic-bezier(.32,0,.2,1), 컨트롤은 별도의 짧은 곡선으로 움직인다. hover를 빠르게 왕복해도 현재 자세에서 이어지는지 본다. 모든 컨트롤을 느리게 만들거나 전역 transition:all을 추가하지 않는다. 필터·입력·실제 결과는 즉시 반영하고 모션 감소·취소에서는 기본 표시를 유지한다.

## 내용에 맞는 반응을 고른다

장면820ms·18px와 CTA420ms는 예제 값이며 카테고리 전체의 고정 모션이 아니다. 대표 작품은 자세 정돈, 탐색 사진은 상세 표식과 작은 확대, 수업 선택은 선택 표시와 가격/폼의 즉시 갱신, 시간표 펼침은 열림 표시 변화처럼 원인과 결과를 연결한다. 업무 목록·입력에는 장면 등장을 전파하지 않는다.

[맥락별 실행 예제](../assets/motion/contextual.html)는 입력→산출물의 제한된 장면, 선택 결과 강조, 짧은 눌림, native details의 상태 회전을 제공한다. 내용 갱신·초점은 즉시 처리하고 장식만 감속한다. hover가 없는 터치에도 선택/상세가 동작하며 press는 취소/손 뗌 후 복귀한다. 부모의 등장·프레임의 자세·안쪽 눌림 레이어를 분리해 transform을 덮어쓰지 않는다. 작은 이동 자체가 더 우수하다는 점수는 만들지 않는다.

한 대표 장면에 유용한 변화만 고르고, 일정·가격처럼 읽는 정보는 안정시킨다. 반복 부유·모든 구간 reveal은 기본값이 아니다. 빠른 왕복, 재선택, 감소 모션의 런타임 변경, JS 실패에서도 표시/조작이 남는지 실행한다.


[편집·상태 실행 예제](../assets/editorial/index.html)는 과정 사진과 선택 결과, 주작품 프레임/상세, 처음 열린 일정의 왕복을 연결한다. CTA hover 숫자를 늘리기보다 사진·캡션·결과 위치를 함께 본다. 사용법은 [USAGE.md](../assets/editorial/USAGE.md)에 있다.

## 기본값의 반복 대신 상태의 성격을 고른다

장면 등장18px·CTA2px·화살표3px를 모든 업종의 세트로 적용하지 않는다. 적합하면 기존 값을 유지하되 움직일 대상이 무엇을 설명하는지 먼저 정한다.

| 상태 | 우선 연결 | 안정적으로 둘 것 |
|---|---|---|
| 업무 행 탐색 | 배경/초점·짧은 누름 | 열 위치·기한·본문 |
| 상품 관심 추가 | 선택 문구·개수 즉시 갱신 | 사진/가격·페이지 위치 |
| 작품/산출물 상세 | 같은 자료·이름·발신 버튼과 복귀 | 필터 범위·원본·조작 가능 시점 |
| 수업/서비스 선택 | 선택 결과 즉시 반영·변경 위치 강조 | 목록 전체·가격의 확정 시점 |
| 행사 장면 | 행사명·일시의 읽는 순서를 해치지 않는 단회 변화 | 날짜·시간·참가 조건 |

hover로 반응하는 비조작 문서는 클릭 가능한 것처럼 오해되지 않게 한다. 자세 변화가 탐색 신호이면 실제 상세 행동과 연결하거나 정적 자료로 둔다. 클릭 결과를 지연시키지 말고 장식만 짧게 연결한다. [상세→복귀 실행 예제](../assets/decisions/index.html#works)는 클릭 자료/제목 유지, 즉시 native dialog, 취소 가능한 짧은 진입, 닫기/Escape 초점 복귀와 필터 유지를 제공한다. 진짜 shared-element 전환 구현이라고 표시하지 않는다. 새 애니메이션 전 이전 것을 취소하고 실행 중 모션 감소 변경에서도 끝 상태가 남게 한다.

## 카테고리의 주인공에 반응을 연결한다

[실행 예제](../assets/category-motion/index.html)에서 업무 상태·상품 상세·수업 요약·메뉴 결과·작품 자세/상세·산출물·일정 표식의 서로 다른 관계를 확인한다. 예제 값은 시작값이며 모든 화면의 버튼을 같은420ms/2px로 통일하는 요구가 아니다. 상태/가격/필수 정보는 즉시 갱신하고 장식만 짧게 이어간다. 정적 사진/문서에 실제 진입이 없으면 클릭을 암시하지 않는다.

새 입력은 이전 장식 애니메이션을 취소하고 마지막 상태가 이긴다. hover 빠른 왕복·도중 상세 열기·Escape·원래 초점·모션 감소 실행 중 변경·터치의 같은 정보 접근을 확인한다. 초기 HTML의 핵심 정보는 JS/모션 실패에도 읽혀야 한다. 콘텐츠를 먼저 숨기고 전체 구간 reveal로 채우지 않는다. transform이 있다는 사실이나 효과 수는 부드러움/우위 인증이 아니다.


[연결 모션 예제](../assets/scene-evidence/index.html)는 사진→같은 자료 상세/관심 결과, 수업→선택 요약, 작품→원본과 짧은 목록/상세, 일정→안전한 SVG 표식을 실행한다. 주효과와 보조를 필요한 대상에만 사용하고 빠른 선택·왕복에서도 마지막 상태를 즉시 반영한다. 펼침 표식은 회전 중·끝·복귀와 글자 확대의 실제 그려지는 범위까지 본다.

## 콘텐츠 묶음의 진입

사진·제목·캡션·행동이 하나의 판단이면 같은 부모에서 정착시킨다. 이미지 혼자 이동하고 설명이 남아 있으면 묶음이 해체되어 보일 수 있다. 배경 색면은 고정하고 안쪽 콘텐츠를 움직이며, 중첩된 부모/자식의 진입 효과를 겹치지 않는다. 같은 행의 비교 카드는 과한 시간차 없이 도착하게 한다.

[실행 모듈](../assets/motion/content-reveal.js)의 contentReveal(elements)는 화면에 들어온 묶음을 한 번만 아래에서 정착시킨다. 시작값16px/780ms/opacity .65는 내용과 표시 크기에 따라 조정한다. 등장 전 콘텐츠를 숨기지 않고, 초점 진입·모션 감소 시 효과를 취소해 즉시 최종 상태로 둔다. 재진입 때 반복하거나 값을 바꾸기 위해 진입 효과를 재생하지 않는다. 호출자가 돌려받은 정리 함수를 페이지/컴포넌트 해제 시 실행한다.

업무 목록은 반복 비교와 입력이 우선이므로 이런 구간 진입을 자동 추가하지 않는다. 소개형 사이트는 PC와 모바일에서 실제 스크롤하며 도착 시점·감속·대상 묶음을 확인한다. 축소 iframe에서는 거리와 글자가 작아지므로 원래 크기 확인도 분리한다. 효과 존재만 검사하지 말고 화면 아래 구간의 실행 계기, 빠른 스크롤, 키보드 초점과 감소 설정도 확인한다.

## 색면과 움직일 대상의 분리

페이지의 구간 색면과 일반 콘텐츠 카드의 이동은 구분한다. 큰 신청/예약 면이 정지해야 하는 설계라면 배경을 가진 section 전체를 진입 대상으로 선택하지 않는다. 바깥 배경/간격은 정지한 채 안쪽 설명·폼 묶음을 선택하고, 중첩된 진입은 제외한다. 실제 실행 중 section과 바깥 면의 transform/translate가 정지하는지 계측한다.

마지막 콘텐츠가 화면에 들어온 뒤 너무 늦게 움직이면 rootMargin과 threshold를 요소 높이·기기 폭에 맞춰 조정한다. 고정된 값의 복사보다 실제 도착 시점을 검토한다. 빠른 스크롤·키보드 초점·재진입·모션 감소에서도 과업의 값과 내용이 그대로 남아야 한다.

## 진입 중 상태를 바꿀 때

사용자가 진입 효과가 끝나기 전에 선택하면 실제 값은 즉시 바꾸고 해당 결과 묶음의 남은 진입을 정리한 뒤 결과 피드백을 적용한다. 부모 진입과 자식 상태 전환이 겹쳐 이동 거리/투명도가 누적되지 않는지 빠른 키보드 선택으로 확인한다. 애니메이션 종료를 기다려 선택 처리를 늦추지 않는다.

## 콘텐츠의 읽기와 역할별 리듬

거리/시간을 카테고리 이름만으로 자동 배정하지 않는다. 큰 작품은 시선을 안정시키는 진입, 기능 선택은 짧은 도착, 날짜/결과 변경은 즉시 이해되는 피드백이 필요할 수 있다. 문장이 바뀔 때는 페이드, 순서가 드러날 때는 작은 방향 이동, 구조가 정돈될 때는 작은 정착을 검토한다. 같은 변화에 매번 다른 효과를 넣지 않는다.

[content-reveal.js](../assets/motion/content-reveal.js)의 distance/duration/fromOpacity를 읽는 묶음별로 선택할 수 있다. 선택 값은 품질 점수가 아니며 새 페이지의 기본값으로 강제하지 않는다. 부모/자식 진입의 중첩, 입력/선택의 지연, 터치/키보드/감소 설정을 실제 화면에서 대조한다.
