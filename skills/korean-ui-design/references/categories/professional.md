# 전문 서비스 · 요청·범위·산출물

## 목적과 구성 선택

가치 제안·문의 행동과 개념 문서/산출물을 동시에 읽어야 하면 좌측 설명·행동과 우측 자료의 병치를 검토한다. 문서를 옆에서도 읽을 수 있는 크기로 편집하며 자료가 길면 핵심 판단을 남기고 전체로 연결한다. 큰 제목→설명→전폭 문서의 세로 적층은 읽는 관계와 높이에 이점이 있을 때 선택한다. 전문성을 문서 면적만으로 표현하지 않는다. 구체적인 선택은 [첫 화면 기준](../hero-composition.md)을 따른다.

확인 가능한 사례/자격이 있으면 증거 중심, 서비스 차이와 의뢰 조건이 중요하면 범위 안내, 전문 글/문서가 핵심이면 편집형 구성을 검토한다. 요청 상황·제공 범위·결과물·절차·문의가 서로 다른 질문에 답하게 한다.

## 자료와 설명 밀도

대표 사례나 문서에서는 요청→핵심 판단→산출물의 관계 한 가지를 실제 크기로 읽히게 한다. 작은 상자·번호·연결선의 수로 구체성을 대신하지 않는다. 실제 납품 자료가 없으면 개념 문서임을 표시하고 고객 로고·성과·검수 표시를 만들지 않는다.

사진·기울어진 종이·특정 색은 필수가 아니다. 문서 전체를 모바일 썸네일로 줄이기보다 중요한 문장과 세로 순서로 재편집한다. 목록의 설명을 대표 장면·상세·폼에 중복 배치하지 않는다.

## 조작과 모션

[산출물 예제](../../assets/category-motion/index.html#professional)처럼 서비스 선택과 설명·결과물·문의 값을 연결한다. 결과는 즉시 갱신하고 필요한 부분만 강조한다. 정적 문서의 클릭 신호나 지속 부유는 실제 행동/읽기에 도움이 될 때만 사용한다.

## 구현과 검토

같은 단계의 번호·본문·행동 기준선과 단계 사이의 관계를 확인한다. 서비스 선택을 양방향으로 바꾸고 문의 오류→수정→확인→완료를 검토한다. 큰 글자에서 문서·선택값·동적 확인창 제목/이메일/닫기/최종 행동의 손실을 확인한다.

[편집 결정](../editorial-decisions.md) · [자료 준비](../asset-pipeline.md) · [모바일 검토](../mobile-review.md). 선택한 기준은 [적용 확인](../applied-evidence.md)으로 최종 DOM·조작·PC/모바일 화면과 대조한다. 수치상 통과와 실제 읽기/광학 판단, 미실행을 구분한다.


## 셀렉트 간격의 일관성

선택 컨트롤이 있으면 같은 제품/비교 범위의 화살표 크기·우측 여백·문구 안전 영역을 공통 토큰으로 연결한다. native 기능과 label/검증/값 갱신은 유지한다. [셀렉트 표시 계약](../control-alignment.md#네이티브-선택-기능과-화살표-표시의-공통-계약)에 따라 실제 모바일·글자 확대·키보드와 연결 기능을 확인한다. 셀렉트가 필요 없는 화면에는 새로 추가하지 않는다.

## 산출물 한 장과 조용한 선택 목록

요청→정리된 판단을 보여주는 문서 한 장의 핵심 문장을 실제 크기로 읽히게 한다. 장식 메모·화살표·번호·색면을 늘려 구체성을 대신하지 않는다. 서비스 목록은 현재 선택만 명확히 구분하고 결과물 패널과 문의 선택을 연결한다. 대표 장면/서비스/절차가 같은 설명을 반복하면 줄인다.

모달 제목은 minmax(0,1fr) 텍스트 열, 닫기는 줄어들지 않는 별도 열로 배치할 수 있다. 390px 두 확대에서 닫기의 전체 조작 상자와 그림이 외곽 안에 남아야 한다. 좌표 일부가 viewport 안이거나 배경 문서 폭이 정상인 것으로 통과시키지 않는다. 각 서비스 확인·수정·완료를 [완료 게이트](../delivery-gates.md)로 실행한다.

## 페이지 관계의 구현 확인

설명용 콘셉트 자료·선택된 서비스·문의 양식은 바탕/내용/선택색의 같은 역할로 연결한다. 섹션마다 별도 테마를 추가하지 않는다. 서비스 상세의 일반 텍스트 화살표 링크도 조작 목록에 포함하고 768px·글자 확대에서 문구와 표식이 분리되거나 가려지지 않는지 검사한다.

공통 구현과 검토는 [페이지 관계 기준](../page-relationships.md)을 따른다.

## 표현 변형과 정보 묶음의 최종 검토

가치 제안·CTA·핵심 산출물은 같은 관계로 읽히게 편집하고 반복 소개 문구는 줄인다. 서비스 개요나 경계선·바탕·간격으로 다음 구간을 연결한다. 다른 테마의 색을 복제하기보다 현재 색 역할 안에서 섹션의 목적을 구분한다.

## 산출물의 편집 완성도

개념 문서는 단색 상자 안에 긴 문장만 나열하지 않고 메타→핵심 제목→질문/판단→다음 행동으로 읽는 위계를 편집한다. 번호/선/프레임은 실제 단계와 정렬을 설명할 때 선택한다. 은은한 종이 깊이나 차분한 배경으로 자료의 경계를 만들 수 있으나 스탬프·검수·실제 실적을 꾸미지 않는다. 본문은 기울이지 않고 모바일·확대에서 제목/단계/조작을 가리지 않는지 확인한다.
