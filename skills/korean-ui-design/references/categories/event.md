# 행사 · 식별·일정·참가

## 목적과 구성 선택

고유 포스터가 행사 식별을 맡으면 전면 그래픽이 유효하다. 행사 소개와 날짜·조건·신청을 동시에 이해하는 것이 우선이면 그래픽/소개와 참가 정보를 병치할 수 있다. 전면형을 행사 기본값으로 정하거나 첫 화면의 같은 제목을 그래픽과 본문에 불필요하게 반복하지 않는다. 구체적인 선택은 [첫 화면 기준](../hero-composition.md)을 따른다.

행사 고유 그래픽이 중요하면 전면 포스터, 프로그램 선택이 중요하면 일정 중심, 지난 기록이 중요하면 아카이브를 검토한다. 큰 영문/로고를 덜어도 한국어 행사명·일시·참가 조건·다음 행동을 파악할 수 있어야 한다.

## 자료와 설명 밀도

실제 자료가 없는 현장·발표자·장소 사진을 만들지 않는다. 자체 타이포/그래픽은 행사 식별을 맡고 일정·조건은 읽기 쉬운 텍스트로 제공한다. 포스터에서 사용한 색의 역할을 프로그램·신청까지 연결하되 각 구간의 대비와 읽기 밀도를 조정한다. 특정 주황·보라·파랑을 고정하거나 신청 구간에 근거 없는 새 강조색을 추가하지 않는다.

시간표는 시간·유형·제목을 빠르게 비교하고 상세 설명은 펼쳐 읽게 할 수 있다. 날짜/유형/금액은 단위와 묶음을 유지한다. 긴 참가 조건은 native select 바깥에서도 읽히게 한다.

## 조작과 모션

[일정 예제](../../assets/category-motion/index.html#event)처럼 설명 상태는 즉시 바꾸고 표식은 그 상태를 나타낸다. 기본 열림·닫힘·왕복을 모두 지원한다. 포스터는 정적/단회 등장을 목적에 따라 선택하고 시간표 텍스트·가격을 지속 이동시키지 않는다.

## 구현과 검토

날짜 선택·건수·프로그램 목록과 유형·인원·합계가 일치하는지 확인한다. 확인창 수정·Escape·초점 복귀·최종 완료도 검사한다. 모바일에서는 시간을 제목 위로 옮길 수 있다.

큰 영문/날짜/가격·안내 첫 줄·회전 SVG를390/768의 두 확대 방식에서 확인한다. 부모 경계와 viewport 경계, SVG 전체 상자와 실제 선의 잘림은 다른 항목이다. 선언 경계가 다른 결과를 같은 점수로 합산하지 않는다. overflow:hidden으로 필수 표식을 숨기지 않는다.

[편집 결정](../editorial-decisions.md) · [자료 준비](../asset-pipeline.md) · [모바일 검토](../mobile-review.md). 선택한 기준은 [적용 확인](../applied-evidence.md)으로 최종 DOM·조작·PC/모바일 화면과 대조한다. 수치상 통과와 실제 읽기/광학 판단, 미실행을 구분한다.


## 셀렉트 간격의 일관성

선택 컨트롤이 있으면 같은 제품/비교 범위의 화살표 크기·우측 여백·문구 안전 영역을 공통 토큰으로 연결한다. native 기능과 label/검증/값 갱신은 유지한다. [셀렉트 표시 계약](../control-alignment.md#네이티브-선택-기능과-화살표-표시의-공통-계약)에 따라 실제 모바일·글자 확대·키보드와 연결 기능을 확인한다. 셀렉트가 필요 없는 화면에는 새로 추가하지 않는다.

## 포스터의 강도와 일정의 읽기 속도

강한 포스터 색/그래픽은 행사 식별을 맡고 일정·참가 폼에서는 같은 역할색을 더 조용하게 쓸 수 있다. 전면 색을 유지할 때도 제목·그래픽·단가·CTA를 모두 같은 크기/굵기로 경쟁시키지 않는다. 대표 그래픽·부가 ODD 로고·장식 통계가 반복되면 가장 유효한 하나를 남긴다. 행사명·일시·조건은 그래픽과 별개로 읽히게 한다.

날짜/건수/전체 프로그램, 참가권×인원의 합계/확인을 [완료 게이트](../delivery-gates.md)로 대조한다. 고정 px 행간을 큰 한글/가격에 전파하지 않고, 안내/회전 표식은 실제 첫 줄과 그림 경계를 검사한다. 상태가 즉시 이해되면 회전 대신 선/기호의 상태 전환을 선택할 수도 있다.

## 페이지 관계의 구현 확인

강한 첫 포스터와 안정적인 일정 목록을 유지하되 신청 구간에서 정보 없는 포스터를 반복하지 않는다. 유형·가격·일정·완료 행동에 집중한다. 일정의 열림/닫힘 상태를 동일하게 맞춰 밀도를 비교하고, 확대 상태의 제목·회전 표식·마지막 신청 행동을 확인한다.

공통 구현과 검토는 [페이지 관계 기준](../page-relationships.md)을 따른다.

## 표현 변형과 정보 묶음의 최종 검토

승인된 상단을 유지하는 수정에서는 프로그램 구간 selector로 변경 범위를 제한한다. 제목·날짜·시간표를 공통 열에 연결하고 임의 퍼센트 들여쓰기와 독립적인 제목 열을 혼용하지 않는다. 일정 열림 상태를 같게 맞춘 뒤 탭·행·섹션 간격을 함께 평가한다.
