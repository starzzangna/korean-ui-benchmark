# 공통 제작 과제

7개 카테고리×4개 조건을 한국어 정적 웹 시안으로 새로 작성한다. 모든 사이트는 shared/data.json의 동일한 사실과 필수 기능을 구현한다. 조건 표기는 no skill / A / B / 자체 스킬이다. 화면에 원본 패키지 이름이나 제작 조건 배지를 넣지 않는다.

공통 자원: shared/fonts/fonts.css, shared/photos, shared/artworks. 사진은 분위기 참고, 상품/작품 SVG는 이 비교를 위한 가상 콘셉트 자료다. 실제 운영·실적·구매·예약·전송으로 표시하지 않는다. 과거 시안·문구·사진·코드를 재사용하지 않는다. 공통 기능 엔진은 동일하게 사용하고 조건별 구도·조판·색·사진 배치·모션은 별도로 작성한다.

최신 소개형 6개 카테고리의 재설계에서는 [CATEGORY_BRIEF.md](CATEGORY_BRIEF.md)가 우선한다. 기존 공개 데이터·기능 부품을 유지하고 조건별 대표 구도와 스타일을 다시 작성했다. 초기 제작의 ‘과거 결과를 가져오지 않음’을 이번 후속 작업까지 처음부터 독립 생성했다는 의미로 확대하지 않는다. 배색·좌우 비율·사진/문구 순서·카드 형태는 공통 요구가 아니다.

- SaaS:4개 업무, 제목/담당 검색과 상태 필터 결합, 상세 상태 수정, 필수 제목/담당/상태/날짜 검증 후 추가, 빈 결과/복구.

SaaS는 [수정된 비교 조건](SAAS_BRIEF.md)에 따라 같은 기능·문구·필수 탐색만 공유하고 배색·구체적 배치·카드·조판·모션은 각 군에서 결정한다. 자체군의 흰 메뉴·보라색·상단 카드 선호를 다른 군에 강제하지 않는다. 구조와 색까지 고정했던 [직전 비교본](../archive/saas-fixed-layout-comparison/index.html)은 보존했다. 다른 카테고리는 기존 과제를 유지한다.
- 브랜드:3상품 분류/검색 결합, 상품 상세, 관심 목록 담기/중복 방지/삭제/빈 상태. 실제 구매 없음.
- 로컬:수업 분류·선택→신청 수업 반영, 모든 날짜/시간/인원, 이름/이메일/데모 확인 검증, 금액, 확인/수정/완료.
- 식당:4메뉴 분류/검색, 빈 결과 복구, 방문일/시간/인원·이름/이메일/확인 검증, 예약 확인/수정/완료.
- 포트폴리오:3분야/전체 필터, 작품 상세의 동일 작업 전체/세부, 확대/맞춤·스크롤, 이전/다음은 현재 필터 범위, 문의 분야3개와 초안 생성/수정.
- 전문 서비스:3서비스 선택과 결과물·문의 선택 연결, 문의 필수값/이메일/설명/확인 검증, 확인/수정/완료.
- 행사:날짜별 일정3개/2개·설명 펼침, 모든 패스/인원별 금액, 필수 입력/확인·수정·완료.

선택지는 데이터의 항목을 누락하지 않는다. 키보드 초점·Escape·모달 닫기/복귀·오류 복구·글자 확대·모션 감소를 포함한다. 320/390/768/1024/1440px을 검토한다. 기능과 문서 넘침 검증을 미적 우위 점수로 해석하지 않는다. 구성과 기능의 즉시 상태 변경을 장식 모션 종료까지 지연하지 않는다.
