# 이번 자체 시안의 팔레트 선택

아래 색은 이번 가상 콘텐츠에 대한 편집 선택이며 카테고리별 고정 규칙이 아니다. 기존 브랜드색이 제공되면 해당 조건을 우선한다. A/B/no skill의 배색은 변경하지 않았다.

| 시안 | 바탕 / 행동색 | 이번 선택의 이유 |
|---|---|---|
| SaaS | `#f6f7fb` / `#5b43d6` | 선택된 흰 좌측 메뉴·보라색 강조·상단 상태 카드형을 자체 시안에 적용한다. 네 군 모두 같은 색 계열과 업무 요구를 따르며 세부 역할값·밀도·표면 표현을 다르게 작성한다. 진행 요약·다가오는 업무는 추가하지 않는다. |
| 브랜드 | `#fcfbfe` / `#72517f` | 노트·달력의 여러 색이 주인공이 되도록 바탕은 거의 흰색으로 두고 탐색·관심 표시에 절제된 자주색을 사용한다. |
| 로컬 | `#f7fafb` / `#395f6b` | 따뜻한 흙 작업 사진과 차가운 읽기 면을 구분한다. 수업 안내·선택·신청에도 같은 청회색 역할을 연결한다. |
| 식당 | `#f9f6ef` / `#9a573f` | 승인된 음식 사진·갈색 상단·크림색 메뉴와 예약의 관계를 유지한다. |
| 포트폴리오 | `#ffffff` / `#40556e` | 작품 색을 보존하는 흰 갤러리 면과 중립 프레임을 사용한다. 추가 색조 필터는 쓰지 않는다. |
| 전문 서비스 | `#f5f8fc` / `#365f8b` | 문서·서비스 범위의 정보 위계를 청회색 면과 진한 잉크 블루로 연결한다. 기존 녹색 문서/선택 면도 함께 바꾼다. |
| 행사 | `#f4f7fa` / `#31566a` | 승인된 남색·호박색 포스터는 유지하고 이어지는 일정·신청 면을 차가운 중립색으로 연결한다. |

소개형 자체 시안의 역할색은 `src/own.css`, 업무 화면의 공통 구성과 군별 표현은 `src/saas-layout.mjs`·`src/saas.css`·`src/saas-conditions.css`에서 지정한다. [SaaS 공통 조건](SAAS_BRIEF.md)에 따라 바탕과 상태·행동의 실제 역할을 확인한다. 색 차이가 디자인 품질이나 스킬의 인과 효과를 입증하지는 않는다.
