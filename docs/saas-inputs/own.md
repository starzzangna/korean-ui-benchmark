# 자체 스킬 입력

[공통 업무 브리프](../SAAS_BRIEF.md)의 ‘네 군에 같은 요구’에 [자체 SKILL](../../skills/korean-ui-design/SKILL.md)과 [SaaS MD](../../skills/korean-ui-design/references/categories/saas.md)를 더한다. 사용자가 선택한 흰 좌측 메뉴·보라색 강조·상단 상태 카드형을 이 군의 선호 방향으로 반영한다. 카드·아이콘 묶음 정렬, 문구 확대, 상태별 전체 건수와 검색 결과의 구분, 기능을 지연하지 않는 모션을 확인한다. 다른 군도 같은 디자인이 되도록 이 선호를 공통 브리프로 올리지 않는다.
