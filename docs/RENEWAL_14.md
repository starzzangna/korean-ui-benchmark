## 조건과 범위

같은 작성자가7개 카테고리×no skill/A/B/자체 스킬의28개 화면을 새 페이지 구성 함수와 스타일로 작성했다. 공통 데이터·필수 기능·글꼴·사용 가능한 사진/가상 작품 자료는 동일하다. `src/renewal/layouts.mjs`의 조건별 구성과 `styles.css`를 사용하며 이전 생성 HTML은 수정하지 않는다. 기존 렌더러의 탐색/고지/모달 프레임과 공통 기능 부품을 재사용한다. 과거 코드와 맥락에서 독립된 최초 생성이나 눈가림 실험으로 해석하지 않는다.

A/B는 [고정 리비전과 해시](input-provenance.json)의 지침을 다시 읽고 적용했다. A는 대상 우선의 큰 장면·동일한 좌우 경계·편집형 목록과 원본 모션 모듈을, B는 한국어 조판·비대칭 사진·따뜻한 바탕·구간 단위 등장·단일 HTML 출력을 선택했다. B의 유틸리티/모션 CDN도 허용했다. 지침의 모든 도구/전체 규칙을 인증받은 결과는 아니며 실제가 아닌 후기·매출·긴급성 등은 공통 사실 계약에 따라 넣지 않는다. 원문은 재배포하지 않고 출처/라이선스 기록을 유지한다.

자체 스킬은 현재 SKILL과 카테고리 MD를 적용해 조건→근거→행동, 모바일 대표 크기, 카테고리별 바탕과 역할에 맞는 모션을 설계했다. 테스트 수로 디자인 우위를 판단하지 않는다.

SaaS는 이전에 합의한 좌측 메뉴·상단 대기/진행/완료3개·업무 목록을 네 조건의 공통 제약으로 둔다. 이 구조까지 무조건 달라야 하는 실험은 아니다. 자체 SaaS에는 진행 요약/다가오는 업무를 추가하지 않는다.

## 최신 보강 적용

- 전문 서비스: 방문자의 조건은 가정으로 명시하고 메시지/흐름/정보 역할의 설계 판단을 서비스 변경과 동기화한다. 판단 근거의 열림과 읽기 기준점을 유지하며 폭/글자 크기에 필요한 공간을 실측한다.
- 작품: 모든 조건에 동일한 NEST 전체/세부 원본을 제공한다. 자체 모바일은 같은 버전의 핵심 크롭과 큰 대표를 쓰고 보조 작업/전체/세부/오류 재시도를 유지한다. 첫 작업의 목록에는 대표 전체를 반복하지 않고 세부 자료를 쓴다.
- 행사: 자체 소개는 활동 문구로 실제 날짜/세션 열림/초점에 연결하고 일정 제목을 중복해 길이를 늘리지 않는다.
- 컨트롤: 공통 네이티브 선택지/화살표·폼 높이·키보드·필수 선택·동의/오류 복구 계약을 공유한다. 모달의 투명 트랙·라운드 안쪽 스크롤을 유지한다.
- 모션: A는 원본 모듈, B는22px/850ms 구간 등장, 자체는 과업에 따라6–12px/480–780ms와 짧은 상태 피드백을 사용한다. 자식 목록이 움직이면 부모 구간은 함께 움직이지 않으며 모션 감소를 존중한다. no skill은 기본 조작 피드백을 제공한다.

## 실행

```sh
npm ci
npm run build
npm run dev
```

`build`는 저장된 새 구성으로28개 화면을 재현한다. AI를 다시 호출하는 명령이 아니다. `results/renewal/조건/카테고리/index.html`에 생성하며 루트 페이지에서 비교한다. `npm test`, `npm run test:branches`, `npm run test:saas`는 새28종을 기본 대상으로 한다. `QA_VARIANT`로 이전 개선본을 명시할 수 있다.

추가 화면 검사에는 실행 중인 서버의 `BASE_URL`과 필요 시 `CHROME_PATH`를 설정하고 `npm run test:renewal`을 실행한다. 결과는 `artifacts/`에 저장되고 공개 보고서는 실행 결과와 보존 해시로 생성한다. 환경 변수/비밀키/유료 서비스는 제품 실행에 필요하지 않다.

이전 실행 파일의 SHA-256, 공통 데이터, 새 결과의 자원 경로를 확인하고 현재 브라우저 검사를 기록한다. 실제 계정·결제·예약·메일 전송은 없는 데모다. 모바일/확대 검사는 에뮬레이션과 CSS 글자 확대이며 실기기·브라우저 메뉴 확대·포괄적인 접근성 인증은 별도다.

공개 루트 index는 새 비교기로 갱신한다. 이전 루트의 원문은 archive/pre-renewal-14/index.source.html에 바이트 그대로 보존하며, 실제 열람용 index.html은 상대 자원 경로만 보정했다. 옛 보존 기준의 루트 index 해시는 이 원문 파일과 대조한다.
