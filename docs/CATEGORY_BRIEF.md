# 6개 카테고리의 조건별 디자인 재비교

## 공통 입력

브랜드·로컬 서비스·식당·포트폴리오·전문 서비스·행사를 같은 데이터와 기능 요구로 다시 설계한다. `shared/data.json`의 이름·제목·설명·가격·일정·선택지는 네 군에서 같다. 제공된 사진·가상 상품/작품·SVG 아이콘과 Pretendard는 네 군 모두 사용할 수 있다. 사진은 참고 자료이며 실제 매장·제품·고객 실적으로 바꾸어 주장하지 않는다.

공통으로 지정하지 않는 것: 대표 화면의 좌우 비율, 전폭 여부, 사진/문구 순서, 팔레트, 제목 크기, 카드/목록 형태, 섹션 간격, 모서리, 모션 표현. 한 군에서 승인된 디자인을 다른 군의 정답으로 전달하지 않는다. 기존 비교 결과를 복사하는 과제가 아니며 공통 기능 부품을 새 구도에 연결한다.

| 카테고리 | 동일 데이터와 필수 기능 |
|---|---|
| 브랜드 | 상품 3개·가격·분류/검색·상세·관심 목록 담기/중복 방지/삭제·빈 상태 |
| 로컬 | 수업 3개·분류·선택/신청 연동·모든 날짜/시간/인원·금액·입력 오류/수정/확인 |
| 식당 | 메뉴 4개·가격·분류/검색·빈 결과·날짜/시간/인원·방문 예약 데모 확인 |
| 포트폴리오 | 작품 3개·분야 필터·동일 작품 전체/세부·확대/맞춤/스크롤·필터 범위 내 이전/다음·문의 초안 |
| 전문 서비스 | 서비스 3개·선택/산출물 갱신·문의 선택 연결·필수값/이메일 검증·확인/수정 |
| 행사 | 이틀의 프로그램 3개/2개·설명 펼침·모든 패스/인원·금액·입력 확인/수정 |

핵심 기능을 모션 종료까지 지연하지 않는다. 선택지 완전성·폼/아이콘 정렬·모달 스크롤·키보드·모바일·글자 확대는 같은 검사 기준이다. no skill도 이 기능·접근성 계약을 완결한다.

## 조건별 입력

| 군 | 디자인 입력 |
|---|---|
| no skill | 위 과제·데이터·공통 기능 부품만. 별도 디자인 스킬을 지정하지 않음 |
| A | 같은 과제 + 고정 리비전의 A 지침·원본 모션 자원. 실제 대상과 자료·정보 위계 중심으로 과제에 적용 |
| B | 같은 과제 + 고정 리비전의 B 지침. 한국어 조판·사진 면·색 역할·재료감·조작 반응을 카테고리에 맞게 적용 |
| 자체 | 같은 과제 + 자체 SKILL·카테고리 MD. 자료/행동 연결·구간 구분·그룹 정렬·확대·조건별 모션을 적용 |

입력 명세는 [no skill](category-inputs/none.md) · [A](category-inputs/a.md) · [B](category-inputs/b.md) · [자체](category-inputs/own.md)다. 외부 지침의 출처/리비전은 [SOURCES.md](SOURCES.md)에 공개한다. 재현용 명세이며 파일을 실행해 AI가 자동으로 새 시안을 생성하는 구조는 아니다.

## 실제 선택한 구도

| 카테고리 | no skill | A | B | 자체 |
|---|---|---|---|---|
| 브랜드 | 일반 사진/문구 병치와 상품 카드 | 상품 3개를 크게 제시한 뒤 가격 비교 행 | 큰 책상 사진과 소개, 차분한 카탈로그 | 넓은 대표 사진과 분리된 소개 패널, 동등한 상품 축 |
| 로컬 | 사진 소개와 수업 카드 | 작업 사진과 구분선 중심 수업 목록 | 사진 프레임과 수업별 독립 신청 카드 | 사진을 먼저 읽는 병치와 별도 안내/일정 묶음 |
| 식당 | 메뉴 진입이 가까운 사진 소개 | 넓은 식탁 사진 아래 조판·간결한 메뉴 행 | 음식 사진 위 짧은 소개·메뉴 진입 | 따뜻한 사진 장면, 모바일 사진/문구 분리·정돈된 예약 |
| 포트폴리오 | 대표 작품과 일반 작품 카드 | 작품을 먼저 크게 보고 설명으로 이동 | 진한 스튜디오 장면·주요/보조 작품·특집 목록 | 흰 갤러리·동등한 대표 프레임과 3열 작품 축 |
| 전문 서비스 | 서비스 소개와 개념 문서 | 문서 우선·범위/산출물 비교 | 진한 문서 면과 겹친 프레임·선택 영역 | 차분한 청회색 문서·서비스/문의의 역할 연결 |
| 행사 | 소개/포스터와 일반 일정 목록 | 대형 인쇄형 포스터·일시/프로그램 위계 | 진한 포스터 장면과 옆 날짜 탐색 | 남색/호박색 포스터·일정/신청 간격의 연속성 |

이 표는 이번 구현의 결과이며 다음 사이트에 강제하는 업종별 템플릿이 아니다.

## 방법과 한계

한 작성자가 네 조건을 적용했다. 데이터·기능 엔진·접근성 부품과 기본 CSS는 공유하고 대표 구도의 구성 함수와 군별 스타일을 분리했다. no skill도 작성자의 기존 지식과 대화 맥락에서 독립적이지 않다. 외부 스킬의 모든 원본 도구/게이트를 실행한 인증이나 스킬만의 인과 효과·통계적 우위의 증명이 아니다. 새 구도와 기존에 유효했던 기능 부품의 재사용을 구분한다.

SaaS 4종은 유지한다. [직전 28개 비교본](../archive/before-category-redesign/index.html)은 실행 HTML·스타일·기능 파일과 함께 보존했다. 상대 경로만 보존 위치에 맞게 조정했다. 공용 사진·폰트 파일은 변경하지 않는다.
