# 대표 대상·선택 연결·상황별 모션의 후속 개선

## 보존과 비교 범위

[새 비교 화면](../refinement/index.html)은 B / 개선 전 자체 / 개선 후 자체를 제공한다. 기본은 B와 개선 후 자체의 두 화면이다. 기존4군28개 HTML·스타일·자료·기능 파일은 그대로 두고 새7개 결과를 `results/refined/`에 생성한다. [기준 파일 해시](../reports/refined-3/baseline.json)의64개 실행 파일/자료가 일치하는지 확인한다. 수정 전 자체 스킬도 `archive/editorial-2-skill/`에 보존했다.

같은 작성자의 후속 개선이며 새로운 독립 비교 실험이 아니다. 공통 사실·가격·선택지·기능 엔진은 유지했다. 자체 개선본에 새로운 개념 그림/설명 예시를 추가했으므로 순수한 지침만의 효과로 설명하지 않는다. 실제 상품·수업·고객 성과·현장 자료를 새로 확보한 것은 아니다.

## 카테고리별 적용

| 카테고리 | 보존한 관계 | 개선한 선택과 실제 결과 |
|---|---|---|
| SaaS | 흰 탐색·보라 강조·3개 상태 카드·간결한 업무 목록 | 중복 열 설명을 덜고 수정/추가로 실제 변한 집계만 짧게 강조. 행 전체를 이동시키지 않음 |
| 브랜드 | 사용 분위기와 상품 상세·관심 목록 | 긴 품목 색인을 짧은 분류 선택으로 바꾸고 해당 필터/상품으로 연결. 대표 상품과 보조 상품을 크게 감상하는 갤러리 |
| 로컬 | 과정 사진→수업 차이→일정/금액 | 반복 단계 안내를 제거. 접시/그릇/머그의 개념 그림으로 형태 차이를 보조하고 수업 선택 후 신청 수업에 초점을 연결 |
| 식당 | 간결한 아이콘/가격 축·따뜻한 예약 구간 | 반복 메뉴 예고를 제거하고 사진을 접시 중심으로 재크롭. 참고 상차림 표시는 유지 |
| 포트폴리오 | 대표 작업·전체/세부·필터 범위·문의 | 대표에서는 제공된 세부 원본, 목록에서는 전체 작업을 보여 반복 역할을 나눔. 작품 감상 면적을 키우고 분야 색인을 실제 필터/상세/복귀와 연결 |
| 전문 서비스 | 의뢰 상황·범위·문의 연결 | 반복 이름 색인 대신 서비스 선택과 요청→정리 방향의 읽을 수 있는 가상 예시. 선택/결과물/문의 값 양방향 동기화 |
| 행사 | 한국어 식별·일시·조밀한 프로그램·패스 | 종이/조각의 개념 그래픽을 추가. 날짜 선택 후 해당 목록만 전환하고 모바일 쉼표 뒤 공백 유지 |

프레임 크기와 실제 대상의 감상 크기를 나누어 검토했다. 상품/작품은 개선 전 이미지와 실제 폭을 대조하고, 음식은 원본의 접시가 남는 크롭을 PC/모바일 캡처로 확인한다. 이는 면적이 큰 안이 항상 우수하다는 점수가 아니다.

## 색인과 조작

- 상품/분야 색인 → 네이티브 분류값 → 실제 노출 대상 → 해당 상세 → Escape 후 원래 초점.
- 서비스 선택 → 설명용 예시·산출물·문의 선택값. 본문과 문의에서 선택해도 상단 예시가 맞춰짐.
- 수업 선택 → 신청 수업값과 다음 입력의 초점 → 인원에 따른 금액. 실제 예약/전송 없음.

장식 종료를 기다려 값을 바꾸지 않는다. 선택과 초점은 즉시 처리하고 도착 자료·새 결과·변한 숫자만 짧게 강조한다. 대표 제목/자료의 최초 진입, 상품/작품 대표 구간의 한 번 등장, 실제 상태 변화는 서로 다른 역할로 적용했다. 재선택과 시스템 모션 감소 전환은 진행 중 효과를 취소한다. 비조작 사진에는 hover 클릭 신호를 추가하지 않았다.

모달의 비동기 닫기 이벤트가 이미 다음 색인으로 옮긴 초점을 가로채지 않도록 개선본의 복귀 정책을 보완했다. `src/refined/app.js`는 빌드 때 공통 기능 엔진에서 생성하며 이 정책만 분리한다. 기존28개 시안의 엔진은 변경하지 않는다.

## 추가 자료와 사실성

`src/refined/assets/plate.svg`·`bowl.svg`·`mug.svg`는 수업 결과 형태의 설명용 개념 그림이며 실제 완성물 사진이 아니다. `material.svg`는 행사 주제를 위한 자체 개념 그래픽이다. 신규 코드/그림은 프로젝트 MIT 범위로 제공한다. [에셋 기록](../src/refined/assets/manifest.json).

전문 서비스의 요청/정리 방향은 설명용 가상 예시로 표시한다. 고객 사례·납품 결과·성과 수치로 주장하지 않는다. 포트폴리오의 세부는 이미 제공된 같은 가상 작업의 세부 파일이다. 기존 사진·작품·글꼴의 권리와 출처는 [기존 자료 기록](ASSETS.md)을 따른다.

## 스킬 반영과 실행

스킬과7개 카테고리 MD에 감상 크기·크롭·반복 구간·색인 결과·상황별 모션을 반영했다. [선택/결과 동작 예제](../skills/korean-ui-design/assets/selection-feedback.html)는 스킬과 함께 복사할 수 있는 실행 가능한 단일 HTML이다. 이번 화면의 배치나 SVG를 다음 프로젝트의 필수 템플릿으로 고정하지 않는다.

```sh
npm run build:refined
npm run dev
```

기본 개발 서버는4300이다. 브라우저에서 `/refinement/index.html`을 연다. 기본4군 비교는 `/index.html`로 유지한다. 추가 검사에는 실행 중인 서버의 `BASE_URL`과 필요한 경우 `CHROME_PATH`를 지정해 `npm run test:refined`를 실행한다. 일반 기능/선택지/SaaS 검사를 개선본에 실행하려면 `QA_VARIANT=refined`를 설정한다. 기본값은 원래4군 검사다. 새 의존성이나 환경 변수 비밀값은 필요 없다.

[최신 검증과 비교 캡처](../reports/refined-3/README.md)는 실제 실행 결과를 기록한다. 기존 보고서는 덮어쓰지 않는다. 글자만200%·글자/행간200%와 브라우저 메뉴 확대는 별개이며, 이번 자동 검사는 앞의 두 종류를 수행한다. 최종 미적 선호와 실기기 평가는 별도다.
