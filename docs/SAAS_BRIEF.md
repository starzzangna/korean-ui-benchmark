# SaaS 재비교의 공통 조건

사용자가 선택한 흰 좌측 메뉴·보라색 강조·상단 상태 카드형 업무 화면을 네 군 모두의 공통 과제로 삼는다. 한 작성자가 같은 데이터·기능 엔진과 의미 구조 위에서 각 조건의 시각 표현을 다시 작성했다. 독립 생성 실험이나 스킬의 인과 효과 측정으로 해석하지 않는다.

- PC: 흰 좌측 메뉴, 워크스페이스/업무 경로, 제목·새 업무, 대기/진행/완료 카드 3개, 검색·상태 필터·업무 목록 순서. 메뉴와 상태 카드는 실제 상태 필터로 동작한다.
- 공통 배색: 흰 메뉴와 읽기 면, 옅은 중립 회색 바탕, 단색 보라색 행동/선택 강조. 오류·완료 등의 의미색은 따로 유지한다. 네 군 모두 Pretendard를 사용한다.
- 공통 사실: `shared/data.json`의 같은 업무 4개와 담당자·기한. 상태별 숫자는 전체 업무 기준이며 검색 결과 수와 구분한다. 수정·추가 시 즉시 갱신한다.
- 공통 기능: 업무명/담당 검색과 상태 필터의 결합, 카드/좌측 메뉴와 필터 동기화, 상세·상태 수정, 필수값 검증 후 새 업무 추가, 빈 결과·초기화, 모달 스크롤·닫기·초점 복귀.
- 모바일: 좌측 메뉴를 접을 수 있는 상단 탐색으로 재배치한다. 상태 카드와 행의 긴 제목·날짜는 화면 폭과 글자 확대에 맞게 줄바꿈한다. 320/390/768/1024/1440px, 글자·행간 200%, 키보드·모션 감소를 검토한다.
- 비교 차이: 위 조건을 유지하면서 각 군의 조판·간격·밀도·경계·모서리·상태 강조·작은 조작 반응을 다르게 작성한다. no skill을 의도적으로 불완전하게 만들지 않는다. A/B의 모든 원본 도구 실행 인증으로 표시하지 않는다.
- 제외: 진행 요약 문장, 다가오는 업무, 가상 지표·후기, 추가 홍보 히어로·장식 사진. 상태 카드 3개는 이번에 명시적으로 선택한 과업 요소이며 모든 SaaS의 필수 규칙이 아니다.

[이전 SaaS 비교본](../archive/saas-before-status-cards/index.html)은 당시 HTML·스타일·기능 파일을 함께 보존했다. 다른 여섯 카테고리의 화면과 디자인은 유지한다.

검사는 `npm test`의 SaaS 범위와 `npm run test:saas`로 실행한다. [카드·메뉴·갱신 검사 결과](../reports/saas-cards.json)는 네 군×PC/모바일 8개 시나리오를 기록한다. 한 시나리오에 여러 기능 검증이 들어가며 독립 실험 표본 수를 의미하지 않는다.
