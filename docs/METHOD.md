# 비교 방법

최신 재제작의 공통 조건·독립 레이아웃 파일·조건별 적용·구도 선택·자료 한계는 [28개 재제작 명세](EDITORIAL_REBUILD.md)에 정리했다.

같은 작성자가 7개 카테고리의 네 조건을 구현했다. 데이터와 기능 계약을 공유하고 페이지 구간·대표 장면·군별 CSS는 별도로 작성했다. no skill도 작성자의 기존 지식과 대화 맥락에서 독립적이지 않다. A·B의 전체 원본 도구/규칙 인증이나 자체 스킬의 통계적 우위를 주장하지 않는다.

기능·정렬·모션·확대 검사는 미적 선호와 별개다. 비교 페이지의 4군/2군·화면 폭·구간 이동·원래 크기 링크에서 같은 상태를 관찰할 수 있다. 장식 모션이 핵심 조작을 지연하지 않아야 한다.

[직전 비교본과 당시 문서](../archive/before-editorial-rebuild/index.html)는 실행 자원·자료·검사 기록을 원본 바이트로 보존했다. 그 안의 더 이전 비교본 링크도 유지했다. 이번의 수정과 기존 관찰을 같은 실행 결과로 합산하지 않는다.
