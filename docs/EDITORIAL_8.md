# 선택 흐름·대표 장면·행사 편집 개선

[B와 비교](../editorial/index.html) · [직전 개선본](../polish/index.html) · [검사 기록](../reports/editorial-8/README.md)

전문 서비스·포트폴리오·행사3개를 편집했다. SaaS·브랜드·로컬·식당4개는 직전 HTML과 실행 자원을 그대로 사용한다. 이전 결과와 자료는 SHA-256 보존 기준으로 대조한다. 같은 작성자의 후속 개선이며 스킬만 바꾼 최초 생성 실험과 구분한다.

## 채택한 관계

| 카테고리 | 선택과 이유 | 줄인 중복·유지한 행동 |
|---|---|---|
| 전문 서비스 | 한 선택 작업대에 가상 전후 예시와 실제 제공 범위를 연결. 가장 강한 면은 선택 결과에 둠 | 큰 선택 그룹은 한 번.3개 서비스·예시/결과물·문의 선택의 양방향 동기화 유지 |
| 포트폴리오 | 첫 화면이 작업 범위를 소개하도록 NEST 웹 콘셉트를 주 작업, RAY 편집을 보조 작업으로 배분 | 긴 대표작 소개 대신 실제 이미지·매체·짧은 캡션. 전체 목록/분류·상세/세부·확대/복귀 유지 |
| 행사 | 행사명·날짜·프로그램 행동을 포스터에 모으고, 옆 소개는 주제와2일/5개 프로그램의 요약을 맡음 | 행사명/날짜의 연속 반복 제거. 프로그램 이동·날짜 선택·세션·패스/신청 유지 |

전문 서비스는 소개 뒤에서 예시와 범위를 다시 고르는 구성을 제외했다. 문의 폼의 서비스 선택은 내용을 확인·수정하는 역할이다. 포트폴리오는 한 작품의 큰 세부보다 두 매체의 범위를 먼저 보여주는 관계를 채택했고, 전체 작품은 목록과 상세에서 감상한다. 행사는 설명 옆 별도 그림과 반복 날짜 대신 포스터 안 행동을 선택했다.

## 에셋 계약

- 주인공: 기존 NEST 전체 원본으로 웹 콘셉트의 구조를 보여준다. 제공된 SVG를 사용하며 원본 밖의 가짜 세부를 만들지 않는다.
- 비교: 기존 RAY 전체 원본으로 편집 매체를 보여준다. 주/보조의 크기 차이는 매체 범위의 소개가 목적이다. PC/모바일에서 전체 이미지와 캡션을 유지한다.
- 결과: 전문 서비스의 전후 문장/흐름은 설명용 가상 예시다. 실제 고객 사례·성과·납품 결과가 아니다. 결과물 목록은 공통 데이터의3개 항목을 그대로 사용한다.
- 키비주얼: 기존 직접 작성한 재료 조각 SVG와 제공된 행사명/날짜를 조판한다. 기존 데모 그래픽의 출처·사실성을 유지한다.
- 부족한 자료: 실제 브랜드 제품·수업 완성 결과·실제 납품 자료는 이번에 확보하지 않았다. 실제 서비스 제작에서는 피사체·빛·거리·안전 영역·권리를 명시해 요청한다.

## 적용 확인

기능 검사와 별도로 한 선택 그룹에서 예시/범위/문의가 함께 바뀌는지, 대표 이미지의 주/보조 크기와 상세 연결이 맞는지, 행사명/날짜가 한 번 편집되고 포스터 버튼이 실제 프로그램으로 이동하는지 검사한다. 모션은 배경을 유지하고 읽는 묶음에 적용하며 초점·모션 감소를 보존한다.

이 개선 결과를 일반적인 생성 성능으로 주장하지 않는다. 다음 스킬 검증은 새 브리프·새 자료와 동일 기능/제작 조건으로 진행해야 한다. 현재 비교는 편집 선택의 후속 효과를 확인하는 범위다.

## 실행

`node scripts/build-editorial.mjs` → `node scripts/serve.mjs --port=4331` → `/editorial/index.html`.

`QA_VARIANT=editorial`로 `scripts/qa.mjs`, `scripts/branches.mjs`를 실행한다. PowerShell은 `$env:QA_VARIANT='editorial'`을 사용한다. 추가 검사: `scripts/editorial-eight-checks.mjs`, `scripts/editorial-eight-motion-checks.mjs`, `scripts/editorial-eight-flow-checks.mjs`. 서버는 `BASE_URL`, Chrome은 `CHROME_PATH`로 지정한다.

B/새 개선본·직전/새 개선본·3종 보기를 제공한다. 함께 이동과 동시 스크롤을 유지한다. 모달 내부는 독립 조작이다. 로컬 데모로 실제 신청/전송을 하지 않으며 GitHub Pages에 배포하지 않았다.
