# 색면과 대표 장면의 후속 개선

[B / 직전 / 새 개선 비교](../atmosphere/index.html)에서 7개 카테고리를 볼 수 있다. SaaS는 직전 개선본의 HTML을 그대로 복사하며 나머지6개를 개선했다. 기존 B·자체·직전 개선본과 실행 자원은 수정하지 않는다. [기준 해시](../reports/atmosphere-4/baseline.json)로 보존을 확인한다. 수정 직전 스킬은 `archive/refined-3-skill/`에 보존했다.

## 대표 구간과 정보 배분

행사는 제목·일시·참가 이유·버튼을 한 묶음으로 옮기고 오른쪽에는 키비주얼을 둔다. 한쪽 열의 그래픽/날짜/설명/버튼이 전체 높이를 결정하던 구성을 줄였다. 실제 PC에서 상단 높이와 양쪽 콘텐츠 높이 차이를 확인하고 모바일에서는 날짜와 행동을 제목 다음에 읽게 한다.

식당은 화면 폭을 쓰는 음식 사진과 가까운 제목/메뉴 진입으로 구성했다. 문구 영역의 국소 명암을 확보하고 음식의 색은 남긴다. 전체 화면 높이를 고정하지 않으며 글자 확대 때 내용에 맞게 늘어난다. 모바일은 별도 크롭과 명암을 사용한다. 실제 메뉴가 아닌 참고 상차림이라는 표시는 유지한다.

## 현재 자료에 맞춘 색면

| 카테고리 | 페이지 바탕 | 목록/읽기 면 | 신청/완료 면 | 근거 |
|---|---|---|---|---|
| 브랜드 | #EEF2EC | #FCFAF4 | #E2E8DF | 기록 도구·종이·달력과 연필의 낮은 채도 |
| 로컬 | #F2EFE8 | #FAF8F2 | #E5EADF | 흙·석재·과정 사진의 온도 |
| 식당 | #F8F1E4 | #FFFAF0 | #EFDDCE | 곡물·과일·따뜻한 식탁과 기존 적갈색 행동 |
| 포트폴리오 | #EFF0F5 | #F9FAFC | #E4E7EF | 다양한 작품색을 보존하는 낮은 채도의 분위기 면 |
| 전문 서비스 | #EAF2EF | #F8FBF7 | #DFEAE4 | 차분한 문서/예시와 기존 청록 계열의 연결 |
| 행사 | #F6E9DD | #FFF9EF | #ECD6C5 | 재료·종이·테라코타 키비주얼 |

이는 이번 가상 프로젝트의 선택이다. 업종별 고정색이나 모든 구간에 색을 넣는 규칙으로 사용하지 않는다. 확정된 브랜드/개인색이 있는 다른 프로젝트는 그 자료로 다시 선택한다. 페이지 바탕·읽기 면·행동 면의 실제 computed 색과 본문/보조 역할색 대비를 대조한다. 밝은 그림·파스텔 위에도 읽을 수 있는 진한 글자와 초점/오류 표시를 유지한다.

색면은 전체 폭에서 역할을 나누고 내용의 기존 정렬 축은 유지한다. 같은 흰색 바탕 위에 박스만 늘리지 않으며 사진과 작품의 원본색에 필터를 적용하지 않는다. SaaS의 읽기 면·상태 카드·목록은 변경하지 않는다.

## 함께 이동과 동시 스크롤

- 구간을 고르고 **함께 이동**을 누르면 모든 프레임이 첫 화면/주요 목록/하단으로 즉시 이동한다. 비교 페이지 바깥 스크롤은 유지한다.
- **동시 스크롤**이 켜져 있으면 어느 쪽에서든 페이지를 스크롤할 때 다른 화면도 전체 길이 대비 같은 진행 위치로 따라간다. 서로 다른 페이지 높이에 같은 픽셀을 강제하지 않는다.
- 동시 스크롤을 끄면 각 화면을 독립적으로 볼 수 있다. 구간 버튼은 꺼진 상태에서도 모든 화면에 적용된다.
- 모달·확대 이미지 내부는 각 화면에서 조작한다. 동시 스크롤은 페이지 위치만 연결하며 선택값·폼 입력을 복제하지 않는다.

검사에서는 구간별 이동·바깥 페이지 위치·양방향 진행률·꺼짐·비교군 전환·모바일을 실제 Chrome에서 조작한다. 프로그램으로 옮긴 프레임의 스크롤 이벤트가 다시 원본을 밀어내지 않도록 되먹임도 막는다.

## 스킬·실행·범위

자체 스킬·색상 기준·DESIGN.md·6개 카테고리 MD에 바탕/읽기/행동 면과 정보량 균형의 선택 기준을 반영했다. SaaS MD와 화면은 유지한다. 자료의 의미·글자 확대·모바일 안전 영역이 먼저이며 이번 배치/색을 공통 템플릿으로 강제하지 않는다.

```sh
npm run build:atmosphere
npm run dev
```

기본 서버4300에서 `/atmosphere/index.html`을 연다. 검사에는 실행 중인 서버의 `BASE_URL`, 필요한 경우 `CHROME_PATH`를 지정해 `npm run test:atmosphere`를 실행한다. 기본 기능/선택값 검사에 새 결과를 포함하려면 `QA_VARIANT=atmosphere`를 사용한다. 기본값은 기존4군이다.

[검사 기록과 PC/모바일 비교](../reports/atmosphere-4/README.md)에 실제 결과를 기록한다. 글자만200%와 글자/행간200%를 구분하며 브라우저 메뉴 확대·실기기·전체 접근성 인증은 별도다. 사진 위 문구는 실제 캡처로 함께 검토한다. 역할색 대비 검사는 사진의 모든 픽셀 대비 인증과 구분한다.

한 작성자의 후속 개선이며 새 독립 실험이 아니다. 실제 전송·예약·결제는 연결하지 않는다. 기존 스톡 사진·개념 작품·개념 그래픽의 사실성과 권리는 [직전 개선 기록](REFINEMENT_3.md)을 따른다.
