# 탐색·강조·콘텐츠 묶음 개선

[B와 비교](../flow/index.html) · [직전 개선본](../purpose/index.html) · [검사 기록](../reports/flow-6/README.md)

SaaS는 직전 시안과 같은 HTML/실행 자원이다. 나머지6개는 같은 작성자의 후속 개선이며 스킬만을 바꾼 독립 생성 실험은 아니다. B와 기존 비교본은 보존 기준의 SHA-256으로 대조한다.

## 모션 선택과 실행

페이지 배경은 정적으로 유지하고 대표 장면·섹션 제목·상품/수업/작품/메뉴·신청을 읽는 묶음으로 선택했다. 이미지와 캡션을 따로 움직이지 않고 부모/자식 진입도 중첩하지 않는다. 기본16px·780ms·긴 감속이며 매 페이지의 효과 개수를 품질로 평가하지 않는다.

화면에 들어왔을 때 한 번 실행한다. 재진입 때 반복하지 않고, 묶음 안으로 키보드 초점이 들어오면 즉시 효과를 취소한다. 모션 감소에서는 콘텐츠가 완전한 상태로 남는다. 입력값·가격·필터·프로그램 결과는 장식 종료를 기다리지 않고 바뀐다.

재사용 구현: [content-reveal.js](../skills/korean-ui-design/assets/motion/content-reveal.js). 사이트는 이 모듈의 별도 복사본을 사용하므로 이후 스킬 편집이 기존 비교본의 동작을 바꾸지 않는다.

## 에셋

[재료 조각 그래픽](../src/flow/assets/poster-material.svg)은 이 데모를 위해 코드로 작성한 개념 SVG다. 실제 작품·행사 제작물이나 사진 자료가 아니다. 작성자: 이 저장소의 데모 제작. 외부 이미지에서 복사하지 않았으며 저장소의 배포 조건을 따른다. 나머지 사진/작품은 기존 자료와 출처를 유지했다. 서비스 문장 예시는 가상이며 실제 고객 성과가 아니다.

## 실행

`node scripts/build-flow.mjs` → `node scripts/serve.mjs --port=4331` → `/flow/index.html`.

`QA_VARIANT=flow`로 `scripts/qa.mjs`와 `scripts/branches.mjs`를 실행한다. PowerShell에서는 `$env:QA_VARIANT='flow'`를 사용한다. 추가 검사: `node scripts/flow-checks.mjs`, `node scripts/flow-motion-checks.mjs`. 실행 서버는 `BASE_URL`, 설치된 Chrome은 `CHROME_PATH`로 지정한다.

비교기는 B/새 개선본·직전/새 개선본·3종 보기를 지원한다. 함께 이동은 해당 구간으로, 동시 스크롤은 문서의 상대 진행률로 연동한다. 서로 다른 구성의 같은 문장을 맞추는 기능은 아니다. 모달/확대 이미지 내부는 독립 조작이다.

로컬 데모로 실제 예약·전송을 하지 않는다. 이번 변경은 GitHub Pages에 배포하지 않았다.
