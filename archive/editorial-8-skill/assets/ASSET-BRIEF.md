# 에셋 제작·수집 요청서

부족한 자료가 실제 구성 결정을 막을 때 작성한다. 이미지 수를 채우는 목록이 아니다. 파일·출처·사용 위치는 확보 후 [ASSETS.template.json](ASSETS.template.json)에 기록한다. 새 라이브러리나 유료 서비스를 필수로 추가하지 않는다.

## 필요한 장면

- **대상과 이유:** 무엇을 보여주어 사용자의 어떤 판단을 돕는가?
- **사용 위치와 행동:** 대표/목록/상세 중 어디에 쓰며 어떤 상품·메뉴·작품·문의와 연결되는가?
- **현재 자료와 차이:** 지금 없는 정보는 무엇인가? 기존 사진의 다른 크롭으로 충분한가?
- **제작 조건:** 피사체·촬영 거리·빛·배경·각도, 함께 노출되는 자료와의 관계. 문서는 실제 읽힐 제목·판단·주석과 익명화 범위.
- **PC/모바일:** 실제 배치의 CSS 크기와 필요한 해상도, 남길 피사체, 텍스트 안전 영역, 별도 세로 원본 필요 여부. 단순히 가로/세로라고만 적지 않는다.
- **출처와 사실성:** 직접 제공/라이선스 자료/참고/생성 중 구분, 저작자·허용 범위. 실물 증거로 사용할 수 있는지.
- **확보 전 대안:** 현재 자료로 가능한 축소 범위, 텍스트 편집, 다른 구도. 없는 내용·후기·제품 사진을 사실처럼 만들지 않는다.
- **채택 확인:** 실제 사용 폭에서 피사체/문서가 읽히고 연결 행동과 같은 대상을 가리키는지, 주변 자료와 빛·밀도가 맞는지.

채택 시 프레임의 폭만 기록하지 않는다. 음식이면 접시가 실제로 남는 위치/크기, 상품이면 형태·소재 식별, 작품이면 전체/세부 가독성을 원본과 나란히 확인한다. PC/모바일 중 한쪽에서 핵심 대상이 사라지면 크롭·비율·원본을 다시 선택한다. 대표와 바로 다음 목록에 같은 자료를 반복할 때는 새 정보가 있는지 적는다. 개념 그림은 설명을 도울 수 있으나 실제 수업 결과·매장·납품 자료의 증거가 아니다.

## 카테고리에 따른 요청 예

| 상황 | 유용한 요청 | 확보 전 가능한 대안 |
|---|---|---|
| 식당의 메뉴 판단 | 제공 메뉴의 실제 한 접시 전체와 재료/질감 근접. 메뉴 이름과 파일을 대응하고 조명·색을 맞춤 | 참고 상차림은 참고로 표시하고 실제 메뉴는 이름·가격·설명으로 비교. 참고 사진을 개별 메뉴 증거로 연결하지 않음 |
| 전문 서비스의 결과 이해 | 익명화한 결과물의 읽을 수 있는 일부, 판단의 전후와 범위. 성과 수치는 제공된 근거가 있을 때만 | 제공된 의뢰 상황·범위로 읽히는 안내를 편집. 콘셉트 예시는 그렇게 표시하며 고객 사례처럼 표현하지 않음 |
| 브랜드의 상품 식별 | 실제 제품 형태·규격을 볼 전체와 소재 세부, 같은 촬영군의 사용 장면 | 제품 개념 그림을 명시하고 비교에 필요한 사실부터 편집 |
| 포트폴리오의 작품 감상 | 원본 전체와 실제 세부, 매체·역할·범위, 확대 가능한 해상도 | 원본이 없으면 가짜 세부를 생성하지 않고 제공된 크기에서만 감상 |
| 로컬 서비스의 선택 | 해당 수업의 실제 과정·결과물과 제공된 공간 정보 | 참고 공간과 실제 수업 정보를 분리하고 일정·수업 차이를 우선 |
| 행사 참여 판단 | 행사 키비주얼 원본과 제공된 프로그램·일시. 실제 사진이 없으면 자체 조판 가능한 원문 | 원문 중심 타이포 구성. 지난 행사처럼 보이는 임의 군중 사진을 증거로 사용하지 않음 |
| 업무 앱의 처리 | 실제 데이터 구조, 긴 값·빈 결과·실패·선택 상태 | 명시한 데모 데이터로 처리 흐름을 설계. 감성 사진으로 빈 화면을 채우지 않음 |

보유 원본 → 사용 가능한 라이선스 자료 → 직접 제작한 개념 그래픽 순으로 가능성을 검토하되 상황에 맞게 선택한다. 생성 이미지는 선택 사항이며 실제 매장·고객·납품·상품의 증거를 대체하지 않는다. 무료 공개 여부와 재배포 허용 여부는 별도로 확인한다.

## 구성 선택에 필요한 에셋 계약

| 역할 | 확보/채택 전에 답할 내용 | 실제 화면 대조 |
|---|---|---|
| 주인공 | 첫 판단에 반드시 필요한 대상·읽힐 면적·원본의 차별점 | 피사체 크기·문구와의 관계·첫 행동 |
| 비교 자료 | 같은 기준으로 비교할 두 대상과 매체/규격 차이 | 같은 축 또는 의도한 우선순위·모바일 식별 |
| 세부/결과 | 전체에서 새로 보여줄 질감·사용·전후 변화 | 같은 대상의 상세 연결·원본 가독성 |
| 키비주얼 | 사용할 원문·행사명·일정·실제 행동 | 옆 소개와 중복 여부·확대·키보드 |

현재 사용 자료/부족한 자료/확보 전 구성을 나눠 기록한다. 새 사진이나 유료 도구 없이 기존 원본과 조판으로 충분하면 추가하지 않는다. 사진 확보가 필요한 경우에는 촬영 대상·빛·거리·질감·PC/모바일 안전 영역·권리/사실성을 구체적으로 요청한다.
