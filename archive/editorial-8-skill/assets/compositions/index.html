사진·작품·문장의 다른 순서

첫 화면을 고르는
여섯 가지 출발점.

업종별 고정 템플릿이 아닙니다. 자료와 방문자의 과업에 맞는 구조를 열어 보고 필요한 부분만 복사하세요. 색·사진·문구는 프로젝트마다 바꿉니다.

01 / 실행 HTML

전면 사진 ↗

공간·캠페인 사진에 충분한 가로 해상도와 문자 자리가 있을 때.

02 / 실행 HTML

사진 먼저 ↗

사진 전체를 살리고 싶거나 중첩 문구를 놓을 자리가 부족할 때.

03 / 실행 HTML

전면 포스터 ↗

날짜·제목·그래픽 자체가 대표 장면을 설명할 때.

04 / 실행 HTML

작품 갤러리 ↗

작업·제품·컬렉션의 실제 감상이 첫 판단일 때.

05 / 실행 HTML

중앙 겹침 ↗

작업 두 개 또는 전체·세부의 관계를 보여줄 자료가 있을 때.

06 / 실행 HTML

설명과 대상 분할 ↗

대상과 설명의 병렬 비교가 방문자의 판단을 도울 때.

원하는 완성감까지 연결하기

주인공의 면적 → 제목·설명의 대비 → 프레임과 여백 → 실제 행동과 감속을 한 묶음으로 정합니다. 사진·프레임에는 여유 있는 감속을, 업무·입력에는 즉각적인 반응을 선택합니다.

각 페이지의 다시 보기·모션 끄기와 작품 원본 보기를 사용할 수 있습니다. 모션 감소와 JavaScript 차단 상태에서도 내용은 표시됩니다. 예제 사진은 실제 해당 매장·브랜드의 사진이 아닙니다.

복사·적용 방법 · 자료 출처

외부 CDN·계정·설치 없이 실행됩니다. 개별 HTML 또는 정적 서버에서 열 수 있습니다.
