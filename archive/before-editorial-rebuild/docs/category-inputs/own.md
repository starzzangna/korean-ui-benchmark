# 자체 · 6개 카테고리 입력

[공통 과제](../CATEGORY_BRIEF.md)의 ‘공통 입력’에 [자체 SKILL](../../skills/korean-ui-design/SKILL.md)과 해당 카테고리 MD를 더한다. 사진·자료와 행동의 연결, 문구 밀도와 구간 경계, 동등 카드/아이콘 그룹 정렬, 선택지·모달·확대·키보드, 상황별 단회 등장과 조작 모션을 확인한다. 고유한 바탕/역할색을 실제 자료·과업으로 선택한다. 이전에 유효했던 기능과 정렬 기준을 유지하되 이전 전체 화면이나 다른 군의 구도를 그대로 복사하는 조건으로 만들지 않는다.
