# 구도 예제 적용

index.html에서 구조를 비교하고 선택한 HTML의 main 안 대표 section을 읽는다. 원본 폴더 구조를 유지하면 로컬 파일이나 정적 서버에서 실행할 수 있다. 외부 CDN·패키지·계정이 필요 없다. 사진과 SVG는 예제 자료이며 실제 매장·판매 상품·고객 작업이 아니다.

## 필요한 부분만 복사

1. hero-composition.md의 조건으로 구조를 정한다. 페이지 이름/색만 바꾸는 방식으로 여섯 시안을 만들지 않는다.
2. 선택한 대표 section의 의미 있는 HTML과 compositions.css의 해당 선택자, 공통 조판/간격만 옮긴다. 기존 프로젝트의 레이아웃·토큰·컴포넌트가 있으면 그 방식으로 재현한다. 모든 예제의 body 테마·데모 바·뷰어·색을 복사할 필요가 없다.
3. 프로젝트의 실제 사진·작업과 글로 교체하고 해상도·크롭·대비·권리를 확인한다. 전면 사진은 가로 여백과 모바일 세로 크롭이 모두 가능해야 한다. 자료가 부족하면 사진 먼저나 목록 중심 구조를 고를 수 있다.
4. 프레임/이미지 반응이 적합하면 motion.css/js를 함께 연결하고 지정 영역에만 KoreanMotion.mount(root)를 호출한다. data-km-tempo=flow는 부모에서 시간 관계를 정하며 전역 컨트롤에 강제하지 않는다. 기존 모션 구현을 사용해도 된다.
5. 대표 행동을 실제 목록·작업 상세·신청 흐름으로 연결한다. demo.js는 구도 전환·다시 보기·원본 이미지 확인을 위한 데모 도구다. 실제 서비스 로직을 대신하지 않는다.

프레임 밖의 회전 여백, 이미지 안쪽 크롭, 포커스 링을 분리한다. CSS transition 축약 선언으로 모션의 transform 전환을 지우지 않는다. 예제의 gallery는 직각 프레임+사진 확대, layered는 놓인 프레임의 자세 정돈을 보여준다. 모바일 layered는 겹침을 풀어 원본과 조작을 보존한다.

## 확인할 동작

- 다른 구조 선택/모음으로 복귀, 대표 행동의 실제 목적지.
- 작품/사진 원본 열기→확대→잘린 부분 이동→맞춤→Escape/닫기→원래 버튼 초점 복귀.
- 이미지 로딩 실패→다시 불러오기. Tab/Shift+Tab 첫·끝 경계.
- 등장 다시 보기, 수동 모션 끄기/켜기, OS 모션 감소의 초기/실시간 변경.
- 320/390/768/1440 실제 화면, 긴 문구/글자 확대, JS 차단 상태의 기본 내용.

예제는 실행 구조를 제공하며 그 자체가 모든 브랜드의 디자인 품질이나 모든 브라우저 호환성을 보증하지 않는다. 완성 화면에서 자료·조판·프레임·시간 관계를 다시 검토한다.
