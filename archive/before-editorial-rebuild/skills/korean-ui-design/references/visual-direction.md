# 기억할 장면과 깔끔한 구성

표현 중심 페이지에서는 대표 대상·조판·면적·자료 편집을 하나의 방향으로 묶는다. 깔끔함은 정보와 장식의 역할이 분명한 상태다. 자료를 빼고 제목/빈 공간만 크게 남기는 방식으로 완성도를 판단하지 않는다.

첫 화면의 구조는 [hero-composition.md](hero-composition.md), 선택한 구도의 완성감은 [visual-coherence.md](visual-coherence.md)로 연결한다. 구도 목록을 읽은 뒤 자동으로 좌 텍스트·우 이미지로 돌아가지 말고, 전면 사진·사진 먼저·포스터·갤러리가 자료에 적합한지 비교한다. 예제는 완성 테마가 아니라 구조를 구현하는 자료다.

## 카테고리별 판단

| 유형 | 대표 장면 후보 | 다음 정보와 연결 | 모바일 편집 |
|---|---|---|---|
| 생활 브랜드 | 제품 실루엣을 보존한 큰 정물 사진 / 사용 맥락의 사진과 간결한 상품 색인 | 가격·종류·상품 상세를 장면 가까이에 | 같은 큰 사진 반복 대신 대표 크롭과 상품 이미지의 거리를 바꿈 |
| 스튜디오 포트폴리오 | 목적을 먼저 구분: 스튜디오 소개는 대표 작업의 관계, 감상은 큰 작품, 탐색은 목록/메타데이터 | 작품 제목·분야와 실제 상세 탐색 | 대표 작품의 비율/겹침과 제목 면적을 새로 편집 |
| 행사 | 날짜가 축인 포스터 면 / 타이포와 실제 프로그램 종류의 대비 | 날짜·프로그램·참가 경로를 함께 찾음 | 데스크톱 포스터 축소에 그치지 않고 숫자·제목·CTA를 재조판 |

각 후보는 실제 자료로 가능한 경우에만 비교한다. 사진이 중요한 요청에서 추상 궤도·아치·문서 도식을 자동 대체하지 않는다. 원색 포스터나 무채색 갤러리도 브랜드 이유가 있으면 가능하다. 특정 색이나 형식을 일괄 금지하는 대신 대상과 정보 위계를 검토한다.

## 콘텐츠에 맞는 구성 선택

[조건별 구성](composition-patterns.md)에서 자료와 방문자의 과업에 맞는 관계를 고른다. 사진의 거리·제목/이미지 비중·메타데이터·반복 리듬·모바일 생략을 실제 콘텐츠로 설명한다. 에셋의 이용 조건과 상표·고유 문구는 별도로 확인한다.

실행 예제는 구도와 상태 관계를 구현하는 자료다. 예제의 배색·문구·정확한 수치를 완성 페이지 전체의 규칙으로 적용하지 않는다. DESIGN.md에는 현재 선택의 이유와 실제 사용 에셋의 권리 정보를 기록한다.

## 대표 화면의 검토

포트폴리오는 [portfolio-composition.md](portfolio-composition.md)를 읽고 목적·주인공·작품 간 관계를 확정한다. 스튜디오 소개형에서 제목과 여백이 작품을 밀어내면 제목을 줄이거나 실제 작품과 함께 배치한 후보를 비교한다. 더 큰 제목·새 색상·등장 애니메이션만 추가하는 방식으로 해결하지 않는다.

제목과 주인공이 경쟁하지 않는지, 제품/작품을 실제로 볼 수 있는지, CTA와 다음 정보가 연결되는지 본다. 한 가지 편집 특징을 여러 구역에 일관되게 이어가되 모든 구역을 같은 카드로 만들지 않는다. 폼·목록에는 별도의 읽기 질서를 둔다. 새 장식을 추가하기 전에 사진/조판/간격 중 해결할 근거가 있는 부분을 고친다.
