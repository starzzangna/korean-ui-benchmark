# 선택한 지침이 화면에 남았는지 확인한다

표현 중심 페이지의 신규 제작·수정에서 사용한다. 기존 스택·자료·사용자 목적을 우선하며 모든 사이트에 같은 사진 비율·열 수·색·효과 개수를 요구하지 않는다. 간단한 부분 수정에는 관련 관계만 확인한다.

## 선언에서 실제 결과로

DESIGN의 유지 계약과 이번 편집 선택 중 결과를 바꾸는 항목을 골라 `기대 관계 → 실제 위치/상태 → 화면 근거 → 판단`으로 연결한다. 통과/실패/미실행/근거 있는 대체를 구분한다. selector 존재와 자동 검사 종료0만으로 편집 판단을 통과시키지 않는다.

| 관계 | 실제 화면에서 확인할 것 | 빠졌을 때 |
|---|---|---|
| 사진→다음 행동 | 사진의 대상과 가까운 이름/캡션/행동이 같은 것을 가리키고 직접 조작하면 기대한 자료/위치로 이동 | 사진과 무관한 CTA, 참고 사진을 실제 상품으로 표시한 관계는 수정 |
| 로컬 과정→수업 선택 | 손/도구/과정과 수업 차이·가격·선택이 한 비교 구간에 있거나 분리 이유가 화면에서 이해됨 | 과정 사진이 하단에 존재한다는 사실만으로 적용 완료 처리하지 않음 |
| 작품→감상/상세 | 실제 크기에서 핵심 형태/특징이 보이고 목록은 이름·분야·핵심 설명, 상세에서 목표/관찰을 읽음 | 정렬된3열도 작품이 너무 작으면2열/대표와 보조 등 다른 배치 검토 |
| 선택→결과 | 수업/서비스/필터 변경 결과가 같은 대상을 가리키고 즉시 반영 | 제목만 바뀌고 그림/내용이 예전 대상이면 연결 미충족 |
| 강조→행동 | 큰 색면·장식보다 주인공/일시/조건/주행동을 먼저 찾을 수 있음 | 고채도 면을 덜어낸 안과 실제 크기에서 비교 |
| 요구→최종 화면 | 지정한 자료 역할·정보 축·탐색 기능이 최종 PC/모바일에서 동작함 | 기본값/깔끔함을 이유로 생략하지 말고 수정 또는 근거 있는 대체 기록 |

사진 크기 자체가 목표는 아니다. 후보 크롭에서 피사체 식별·실제 감상 크기·다음 행동을 함께 비교한다. 같은 사진 반복에는 새 관찰 정보가 있어야 한다. 읽히지 않는 작품 내부의 작은 글자를 외부 설명으로 늘려 대신하지 않는다. 원본을 열어 읽을 수 있게 하고 목록의 작품은 구별 가능한 크기로 편집한다.

## 증거 기록

현재 프로젝트의 실제 항목만 남긴다. 예를 들어 `과정 사진과 수업 목록 / #classes / 1440·390 기본·선택 후 / 캡처 경로 / 통과 또는 분리 이유`처럼 적는다. 숫자 기준을 사후로 낮춰 실패를 지우지 않는다. 자동 후보가 아닌 편집 판단에는 판단 이유를 남긴다. 미실행은 통과가 아니다.

같은 행의 카드 축을 보존한 채 열 수·이미지 비율·설명 위치를 조정할 수 있다. 마지막 카드 임의 전폭 확대, 설명마다 고정 높이로 자르기, 본문 축소로 감상 공간 확보는 피한다. 표준 비율과 실제 원본이 충돌하면 원본별 contain/크롭을 선택한다.

## 장면과 동작의 근거

주효과와 보조 효과를 필요한 만큼 선택한다. 사진 반응→상세→원래 초점, 수업 선택→금액→신청, 작품 자세→상세→복귀, 서비스 선택→산출물, 일정 펼침→표식처럼 같은 대상의 상태 관계로 검토한다. 이동량·지속 시간·효과 수를 품질 점수로 삼지 않는다. 반복 부유는 문서 읽기/입력에 도움이 되는지 별도 판단한다.

[실행 예제](../assets/scene-evidence/index.html)는 같은 자료 상세/관심 피드백, 과정과 선택, 감상 크기/설명 분리, 안전한 일정 표식을 보여준다. CSS/JS 전체 사이트를 템플릿으로 복제하지 않는다. 빠른 왕복과 새 선택은 이전 장식을 취소하고 마지막 상태를 즉시 표시한다.

## 회전과 글자 확대

요소 상자가 화면 안이어도 회전된 `+` 문자·자식 SVG·가상 요소는 바깥으로 그려질 수 있다. 기본·열림·hover/복귀와 글자만/글자행간2배를 분리한다. 390·768을 포함한 필요한 폭에서 요소 rect와 문자 Range를 함께 본다. 의도된 확대 이미지의 내부 스크롤과 필수 아이콘의 문서 바깥 넘침을 구분한다.

글자 표식 대신 SVG 선 도형을 사용하면 폰트 영향은 줄지만 확대 안전성이 자동 보장되는 것은 아니다. 회전 wrapper와 글/행동 wrapper를 나누고 아이콘의 자체 크기·여유·조작 영역을 확보한다. `scripts/layout-probes.js`의 `measureVisualBounds`와 감사기의 `visualBounds` 계약은 지정한 대상의 가로/양축 범위를 확인한다. pseudo·광학적 잉크/그림자·모든 상태는 수동 화면 검토가 필요하다. overflow:hidden으로 필수 표시를 숨겨 통과시키지 않는다.

## 기본 기능의 실제 적용 증거

선택지가 있으면 독립 요구 목록→실제 `select.options`→각 필수 선택값→그 값의 완료 결과를 연결한다. 문서에 세 값을 적었거나 한 값의 제출에 성공한 것은 나머지 분기 통과가 아니다. 동적 필드는 해당 상태를 연 뒤 대조하며 프로그램 필터/문의 유형처럼 라벨이 비슷한 필드의 역할을 구분한다.

라운드 상세 모달은 외곽 클리핑→가용 높이의 본문 스크롤→상하 모서리와 투명 레일→최하단 실제 행동→닫기/초점 복귀를 연결한다. 선언된 CSS와 외곽 상자 좌표만으로 시각·내용 접근을 인증하지 않는다. [모달 확인 기준](dialog-scroll.md)의 기본/긴 내용·PC/모바일·두 확대 상태를 해당 화면에서 실행한다.

## 첫 섹션의 구도 근거가 있을 때

선택한 구도의 이름만 확인하지 않고 실제 PC 화면에서 문구·대표 자료·첫 행동이 의도한 관계로 읽히는지 본다. 병치에서는 대상의 식별 면적·텍스트 길이·행동 연결을, 전면/적층에서는 큰 면적이 전하는 정보와 첫 행동·다음 구간까지의 거리를 확인한다. 전폭 사용률이나 한 화면 안 CTA 개수를 점수로 삼지 않는다. 대표 자료의 가독성을 유지한 채 관계를 개선할 수 있는지 판단한다. 모바일/확대에서 순서를 바꾼 이유도 기록한다. 여러 사이트는 제출 후 첫 섹션을 나란히 검토하되 독립 작성자에게 다른 작성자의 결과를 사전 제공하지 않는다.
