03 / 행사 · 타이포 조형

첫인상의 짧은 여운

타이포 장면의 단회 등장. 무한 반복이나 스크롤 조작 없이 읽는 흐름을 이어갑니다.

레시피 상세 보기 ↗키보드 Tab → Enter로도 열 수 있습니다.
텍스트로 구현 원리 읽기

바깥 장면은 18px·580~820ms로 한 번 등장합니다. 안쪽 프레임은 ±1.5도, 대표 CTA는 -2px, 화살표는 3px 움직입니다. 모션을 끄거나 자바스크립트를 사용할 수 없어도 콘텐츠는 표시됩니다.

터치에서는 탭 한 번으로 상세를 엽니다. 호버로만 보이는 내용이 없습니다. 시스템의 모션 감소 설정과 수동 끄기를 모두 따릅니다. 수치는 CSS 변수로 조정할 수 있습니다.

레이어를 나누는 작은 원칙

장면 wrapper에는 등장 이동만, frame에는 회전만, 이미지 전용 wrapper에는 확대만 적용합니다. 기존 이미지에 transform이 있어도 별도의 바깥 레이어를 사용해 보존합니다.

모션은 필수 정보나 조작을 지연시키지 않습니다. Escape 키로 닫으면 원래 버튼으로 초점이 돌아갑니다.
