# 브랜드 인상을 만드는 대표 장면

브랜드·매장·식당·전문 서비스 소개에서 사용한다. 이미 사용자가 선택한 분위기와 기존 브랜드를 우선한다. 업무 처리·검색 중심 앱과 부분 컴포넌트 수정에는 이 과정을 강제하지 않는다.

## 인상과 과업을 함께 선택한다

DESIGN.md에 방문자가 무엇을 느끼고 무엇을 할지 한 문장으로 쓴다. 예: ‘손에 든 찻잔과 나무의 온도를 먼저 느끼고 세 물건을 살펴본다’, ‘공간에 머물고 싶은 인상을 만든 뒤 수업과 날짜를 고른다’. ‘고급·깔끔·세련’만으로 결정하지 않는다.

| 목적 | 먼저 완성할 대상 | 다음 행동과 연결 |
|---|---|---|
| 브랜드 소개 | 대표 사진·이름·짧은 문구의 관계 | 상품/컬렉션의 진입점이 첫 장면에서 보임 |
| 공간 방문·수업 | 공간의 표정과 사람의 행동, 참고 범위 | 일정·가격·신청으로 이어짐 |
| 식당 소개 | 상차림·빛·식사의 분위기와 메뉴의 성격 | 메뉴/가격과 방문 선택으로 이어짐 |
| 전문 서비스 소개 | 목표·과정·결과물을 구체화한 개념 장면 | 해당 서비스 설명과 문의로 이어짐 |
| 빠른 상품 탐색 | 비교 가능한 사진과 가격 | 짧은 브랜드 인상 안에서 검색/분류 제공 |

정보에 빨리 도달하는 것과 기억에 남는 인상을 따로 검토한다. 소개 장면을 거대하게 만들어 실제 과업을 지연시키거나, 빨리 보여준다는 이유로 대표 표현을 모두 없애지 않는다.

## 사진을 한 촬영의 언어로 편집한다

같은 면적의 사진 세 장이 곧 하나의 브랜드 장면은 아니다. 빛의 방향·색온도·배경·거리·피사체 비율이 다른 자료를 전면에 동시에 놓으면 차이가 먼저 드러난다.

- 가장 잘 맞는 사진 하나를 주인공으로 정하고 다른 사진은 비교/과정/상세의 역할로 줄인다.
- 같은 물건의 전체와 세부, 공간과 손의 행동처럼 관계가 읽히는 조합을 쓴다. 사진을 무작정 더 추가하지 않는다.
- 불일치가 큰 사진군은 대표 장면과 상품 목록으로 역할을 분리한다. 실제 자산을 확보할 수 있으면 같은 조명/배경의 촬영 계획을 적는다.
- 크롭은 실제 피사체를 보고 결정하고 모바일에서 다시 정한다. 멋있어 보이는 비율 때문에 손·제품·이름을 잘라내지 않는다.
- 참고 자료의 표시는 유지한다. 색 보정이나 새 촬영이 필요하면 실제 작업 범위와 권리를 확인한다.

## 개념 시각화와 허위 증거를 구분한다

실제 납품 문서가 없어도 제공된 서비스 내용을 개념 문서·사용 흐름·종이 조판·도형으로 시각화할 수 있다. ‘목표 → 범위 → 다음 행동’ 문서 모형은 설명 수단이다. 이를 고객 납품물·사용 실적·인증으로 소개하면 허위 증거가 된다.

`개념 미리보기`처럼 성격을 명확히 하고, 내용은 제공된 과정·결과물에서 가져온다. 가짜 고객명·검수 도장·실적 숫자·실제 앱으로 오인할 작동하지 않는 UI를 붙이지 않는다. [실행 가능한 문서 장면](../assets/scenes/plan-board.html)은 개념을 구현하는 예이며 새 브랜드의 고정 테마가 아니다.

## 깊이와 조판을 함께 만든다

주인공을 크게, 보조를 작게 두고 캡션·행동의 정렬 축을 정한다. 종이/사진/제품의 성격에 맞는 경계·앞뒤·그림자·필요한 작은 기울임을 조합한다. 전면 사진·평면 타이포·정렬된 UI는 다른 방식으로 완성될 수 있으므로 모든 장면을 겹친 종이나 아치로 만들지 않는다.

제목은 글꼴 이름이나 크기만 비교하지 않는다. 문장의 덩어리·줄 끝·행간·사진과의 높이 관계로 조정한다. 같은70px 제목도 한 줄의 목록 제목과 두세 줄의 브랜드 문장은 역할이 다르다. 한국어를 한 글자씩 세로로 쪼개지 않는다.

## 사진 모서리의 부드러움

라운드는 사진의 역할과 브랜드 인상으로 고른다. 부드러운 생활·매장 사진이라면 큰 사진 16–24px, 작은 보조 사진 10–16px을 시작 후보로 비교한다. 전면 배경은 화면과 맞닿는 변을 직각으로 유지하고 노출되는 하단 모서리만 둥글게 할 수도 있다. 모든 카테고리를 같은 둥근 카드로 바꾸거나 인물·작품에 무조건 원형 마스크를 씌우지 않는다.

테두리가 있는 프레임은 바깥 반경과 테두리 두께를 함께 정하고 안쪽 반경은 그만큼 줄인다. 작품·문서 원본은 모서리의 정보까지 보존한다. 필요하면 프레임 안에 여백을 두며 확대·이동 뷰어의 실제 원본은 둥근 마스크로 자르지 않는다. 종이·로고·입력까지 사진 반경을 전역 전파하지 않는다.

확대·기울임이 있는 사진은 고정 마스크와 움직이는 이미지를 분리해 모서리 밖으로 새지 않게 한다. 초점 링·캡션·재시도 버튼이 잘리지 않는지 모바일·hover·오류 상태에서 확인하고 선택한 반경과 예외를 DESIGN.md에 기록한다.

## 정지 → 등장 → 반응 → 복귀

정지 상태만 봐도 무엇을 소개하는지 읽히게 한 뒤 동작을 연결한다. 대표 사진의 작은 확대, 종이 자세의 정돈, 캡션과 주인공의 짧은 등장 차이 등 한 장면의 관계를 강화한다. 효과 개수를 늘리는 대신 주인공과 행동의 시간·끝 상태가 어울리는지 본다. 모든 구역 reveal·무한 부유를 기본으로 붙이지 않는다.

배경 사진은 클릭 대상으로 오인시키지 않는다. 실제 탐색 사진은 상세 열기·키보드·초점 복귀까지 연결한다. 선택/오류/결과는 모션 종료를 기다리지 않는다. [장면 컴포넌트](../assets/scenes/USAGE.md)와 [모션 사용법](../assets/motion/USAGE.md)을 필요한 부분에만 사용한다.

## 실제 화면에서 통과시킬 기준

1. 첫 화면에 이 브랜드의 주인공이 있고, 큰 제목과 빈 공간만으로 인상을 대신하지 않는다.
2. 사진군·프레임·문구·행동이 같은 성격을 공유한다. ‘정돈됨’과 ‘대표성이 있음’을 따로 평가한다.
3. 다음 과업이 보이며 장면을 위해 가격·일정·작업 탐색을 불필요하게 밀어내지 않는다.
4. 모바일에서도 같은 인상이 남고, 큰 글자에서 로고·메뉴·날짜·입력이 서로 겹치지 않는다. 문서 폭만 유지된 것으로 완료하지 않는다.
5. 대표 반응과 복귀를 실제 크기로 보고, 입력/초점·터치·모션 감소가 동작한다.

이는 화면 검토 기준이다. 임의의 점수를 만들어 모두의 취향이나 스킬의 승리를 인증하지 않는다. 취향이 갈리는 어두운/밝은 면, 감상형/탐색형, 사진 형태는 목적과 사용자 선택으로 결정한다.
