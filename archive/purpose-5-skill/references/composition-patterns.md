# 조건별 구성 선택

구성은 콘텐츠의 우선순위와 다음 행동을 드러내는 수단이다. 아래 패턴은 서로 다른 선택지이며 특정 사이트·색·서체·비율을 복제하는 템플릿이 아니다.

| 패턴 | 적합한 조건 | 핵심 관계 | 모바일에서 확인할 것 |
|---|---|---|---|
| 전면 이미지 | 식별력 있는 대표 사진과 짧은 메시지 | 피사체→제목/캡션→관련 행동 | 피사체 안전 영역·문자 대비·메뉴/행동 접근 |
| 이미지 먼저 | 사진의 맥락을 먼저 보고 설명을 읽어야 함 | 충분한 감상 면적→인접 정보/다음 행동 | 가로 원본의 크롭·사진 뒤 설명 길이 |
| 설명과 대상 병치 | 대상과 선택 기준을 함께 판단해야 함 | 문구와 자료의 같은 대상 연결 | 위아래 순서·장문 뒤로 밀리는 자료 |
| 대표/보조 자료 | 자료 간 차이나 연속성이 소개에 중요함 | 주인공의 크기→다른 분야/세부 단서 | 겹침 해제·원본 보존·가려지지 않는 조작 |
| 포스터/타이포 | 고유 문자·그래픽과 일시/참가 정보가 중요함 | 행사 식별→일정/조건→탐색/신청 | 큰 문자 재조판·가격/날짜 분리·확대 넘침 |
| 비교 목록/색인 | 여러 항목을 빠르게 찾거나 비교함 | 분류→동등 정보 축→해당 상세 | 열 재배치·필터 범위·긴 문구·빈 결과 |

## 선택 기준

- 설명·자료·행동을 동시에 판단해야 하면 병치, 충분히 감상한 뒤 설명을 읽어야 하면 장면 우선을 검토한다. 패턴 표의 순서는 추천 순위가 아니며 분할/전면형의 할당량은 없다.
- 실제 자료가 해당 패턴에서 식별되는지 먼저 확인한다. 원본 비율과 필요한 정보량을 본 뒤 제목 크기·여백·프레임을 조정한다.
- 사진 위 문구는 의미 있는 안전 영역과 대비가 있을 때 사용한다. 피사체나 긴 한글과 충돌하면 문구를 인접 면으로 옮긴다.
- 같은 구간의 행동은 관련 대상을 가리킨다. 전체 컬렉션을 소개하는 장면과 개별 상품을 증명하는 상세 사진을 구분한다.
- 대표 장면의 비대칭과 비교 목록의 정렬은 다른 목적이다. 강조할 대상이 없는 비대칭으로 카드의 우연한 어긋남을 합리화하지 않는다.
- 모바일은 읽는 순서와 자료 크기를 다시 편집한다. PC의 여러 창을 한 화면에 모두 축소하거나 필수 일정/조건을 생략하지 않는다.

## 동작과 검토

메뉴 진입은 들어오는 방향을, 펼침 표식은 열림/닫힘을, 자료 전환은 대상의 바뀜을 설명할 때 translate/rotate/opacity를 선택한다. 자동 재생·반복 부유·연속 스크롤 등장은 별도의 콘텐츠 목적이 있을 때만 사용한다.

첫 화면·목록·마무리를 실제 크기로 확인한다. 대상의 식별, 정보 찾기, 행동 결과, 기본/확대의 손실을 따로 기록한다. [구도 예제](../assets/compositions/index.html)는 필요한 관계만 구현하는 자료이며 전체 페이지의 기본 테마가 아니다.
