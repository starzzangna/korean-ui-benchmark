# 로컬 서비스 · 방문·수업·예약의 연결

## 소재와 선택 단계의 색면

공간·흙·도구의 실제 색에서 분위기 면을 정하고 수업 비교와 일정 확인의 읽기 면을 구분한다. 흙빛은 선택 가능한 근거이지 모든 매장의 기본 갈색이 아니다. 이미지를 담은 패널만 색칠하고 큰 구간을 모두 흰색으로 두는 선택도 실제 구분 효과를 검토한다. 번호·선·색면을 동시에 늘리지 않는다.

## 수업의 차이와 매장의 인상을 함께 전달하기

가격표를 정돈하는 것만으로 매장 인상을 완성하지 않는다. 공간/과정 사진에서는 손·도구·행위가 읽힐 크롭을 정하고, 수업 비교에는 기법과 완성할 물건을 구별할 정보를 둔다. 실제 결과물 사진이 없으면 개념 그림임을 명확히 표시한 형태 설명을 선택할 수 있다. 한 과정 사진을 여러 수업의 실제 결과로 주장하지 않는다.

번호·단계 안내·구분선·카드 배경을 모두 반복하지 않고 내용의 역할로 구간을 나눈다. 수업 선택은 신청 수업·일정·금액 확인으로 이어져야 한다. 값을 즉시 반영하고 필요한 다음 조작으로 안내하며 결과 표식만 짧게 강조한다. 키보드 초점을 장식 종료까지 기다리게 하지 않는다.

## 목적과 구성 선택

수업·방문 조건과 공간/과정 사진을 함께 판단해야 하면 설명·선택 안내와 사진을 병치할 수 있다. 공간 자체의 감상이 방문 판단을 좌우할 때는 넓은 장면을 검토한다. 큰 제목→긴 공간 사진→수업 목록의 적층이 첫 선택을 불필요하게 밀지 않는지 확인한다. 구체적인 선택은 [첫 화면 기준](../hero-composition.md)을 따른다.

공간 인상이 중요하면 장소 중심, 가격 비교가 중요하면 서비스 목록, 수업/방문 시간 선택이 중요하면 일정 중심으로 구성한다. 소개·서비스 비교·신청은 제목·간격·정보 역할로 구분한다. 서로 다른 수업을 가격 차이만 있는 요금제로 축약하지 않는다.

## 자료와 설명 밀도

공간은 방문 맥락, 손·도구·과정은 서비스 차이를 설명한다. 사진이 주는 새 정보와 인접한 이름·내용·가격·선택을 연결한다. 한 과정 사진으로 모든 수업을 증명하지 않는다. 실제 주소·운영시간·일정·자격은 확인된 자료만 표시하고 분위기 사진과 실제 매장 사진을 구분한다.

빛·재료·브랜드에서 색을 정하며 갈색이나 커피 정물을 업종의 기본값으로 삼지 않는다. 사진이 부족하면 필요한 대상·구도·촬영 조건을 기록하고 정확한 텍스트/일정으로 보완한다.

## 조작과 모션

[선택 예제](../../assets/category-motion/index.html#local)처럼 항목 선택·폼 값·단가·인원 합계를 같은 서비스에 연결한다. 데이터는 즉시 바꾸고 바뀐 요약에만 제한된 강조를 줄 수 있다. 비조작 사진의 hover나 선택할 때마다 신청 위치로 강제 스크롤하는 동작은 필요성을 따로 판단한다.

## 구현과 검토

목록 선택과 폼 select를 양방향으로 조작한다. 이름·내용·가격·선택의 묶음, 일정·인원 합계와 오류 복구를 확인한다. 좁은 배지·회전 표식은 긴 문구/확대에서 일반 캡션으로 바꿀 수 있다. native 옵션이 길면 짧은 식별 문구와 외부의 전체 조건/합계를 함께 제공한다.

[편집 결정](../editorial-decisions.md) · [자료 준비](../asset-pipeline.md) · [모바일 검토](../mobile-review.md). 선택한 기준은 [적용 확인](../applied-evidence.md)으로 최종 DOM·조작·PC/모바일 화면과 대조한다. 수치상 통과와 실제 읽기/광학 판단, 미실행을 구분한다.


## 셀렉트 간격의 일관성

선택 컨트롤이 있으면 같은 제품/비교 범위의 화살표 크기·우측 여백·문구 안전 영역을 공통 토큰으로 연결한다. native 기능과 label/검증/값 갱신은 유지한다. [셀렉트 표시 계약](../control-alignment.md#네이티브-선택-기능과-화살표-표시의-공통-계약)에 따라 실제 모바일·글자 확대·키보드와 연결 기능을 확인한다. 셀렉트가 필요 없는 화면에는 새로 추가하지 않는다.

## 구간의 연결과 필터 폭

공간 소개→수업 차이→신청이 각각 새 질문에 답하게 한다. 과정 사진을 독립된 감성 문구 구간으로 반복하기보다 무엇을 배우고 어떻게 선택하는지와 연결한다. 번호·분류 배지·카드 배경·테두리 중 정보 구분에 필요한 것만 남긴다.

단일 수업으로 필터했을 때 auto-fit이나 단일 자식 규칙으로 카드가 전폭 확대되지 않게 한다. 동등 비교는 열 수/남은 자리 또는 최대 카드 폭을 유지하고, 모바일 한 열과 구분한다. 수업3값 등 실제 요구 목록과 날짜/시간/인원·단가→합계·확인을 [완료 게이트](../delivery-gates.md)로 대조한다. 전체 조합이 작으면 전수 실행할 수 있고 크면 각 필수 값과 경계 조합을 남긴다.

동등 열을 유지하는 시작 구현으로 `assets/controls.css`의 `.kui-comparison-grid`를 선택 적용할 수 있다. 실제 열 수/분기 폭은 프로젝트에 맞추고 필터가 열 정의를 바꾸지 않게 한다.

## 페이지 관계의 구현 확인

수업·서비스를 비교하는 구간이 반복 가격표처럼 보이면 이름·설명·가격·선택의 같은 축을 가진 행 구성을 검토한다. 넓은 화면과 중간 폭, 모바일의 읽는 순서를 각각 정한다. 장면 사진은 실제 판단에 필요한 공간·활동이 크롭에서 남는지 확인한다.

공통 구현과 검토는 [페이지 관계 기준](../page-relationships.md)을 따른다.

## 표현 변형과 정보 묶음의 최종 검토

수업 행은 번호/분야·이름/설명·가격/선택의 관계를 명시한다. 중간 폭에서 내용과 행동을 같은 맥락으로 재배치하고, 모바일에서는 가격/선택을 연결한다. 선택 버튼은 배경만 채우지 않고 좌우 padding·최소 크기·전체 중앙·선택/취소·초점을 함께 정의한다. 필터와 신청 행동의 색 역할도 연결한다.

## 장면 소개에서 선택 목록으로 전환

사진의 설명 캡션, 다음 행동을 안내하는 문구/일정, 실제 수업 선택 목록은 역할이 다르다. 안내·일정이 캡션처럼 읽히면 해당 묶음의 앞쪽 간격·역할 라벨·배경/경계·조판 중 필요한 수단으로 분리한다. 묶음 아래에 선을 긋는 것만으로 위 사진/캡션과의 구분을 해결했다고 판단하지 않는다. PC는 안내와 일정을 같은 묶음으로, 모바일/확대에서는 의미 순서대로 재배치한다. 특정 배경이나 카드 형태는 공통 기본값으로 강제하지 않는다.

## 상단과 본문의 연결 판단

매장명과 수업 탐색의 위계로 GNB를 정한다. 흙·작업 사진의 분위기에서 수업 비교로 넘어갈 때 제목과 여백 또는 읽기 면을 분명히 하고, 예약 면의 색은 앞 자료와 연결한다. 업종만으로 중앙 로고·녹색 예약을 고정하지 않는다. [공통 선택 기준](../header-and-surfaces.md)을 실제 메뉴 수·자료·방문 과업에 대조한다.
