# 사진 편집과 작업 유형별 상세

브랜드의 사진 중심 화면, 포트폴리오의 프로젝트 상세를 만들 때 읽는다. 이미지 비율을 다르게 하는 것 자체가 목적은 아니다. 사용자가 대상을 이해하고 선택하는 데 필요한 차이를 만든다.

## 브랜드: 사진의 역할부터 편집한다

실제 파일을 열어 피사체·방향·여백·조명·해상도를 확인한다. 대표 장면(사용 맥락), 목록(비교), 상세(형태와 확인할 부분)에 어떤 사진을 쓸지 정한다. 같은 사진을 여러 번 쓰면 각 위치의 역할을 설명할 수 있어야 한다. 첫 화면과 바로 다음 구역에 같은 크롭을 크게 반복하지 않는다.

- 광원·배경·색 온도가 다른 사진을 필터 하나로 통일하지 않는다. 비슷한 촬영군을 우선 고르고, 부족하면 여백·면적·순서로 편집한다. 제품에 임의 색보정을 하지 않는다.
- 세로 사진의 실루엣, 가로 사진의 공간 맥락처럼 실제 내용에 맞게 비율과 object-position을 정한다. 순번(:nth-child)이 아닌 에셋/상품 ID에 크롭을 연결해 필터 후에도 유지한다. 모바일과 중간 폭에서 피사체가 잘리지 않는지 확인한다.
- 분위기 컷에서 관련 상품이나 목록으로 연결할 때 독립적인 선택 버튼의 이름을 분명히 한다. hover 외에도 키보드·터치에서 상세 진입이 가능해야 한다. 사진 확대 중에도 주변 글자와 영역 높이는 흔들리지 않게 한다.
- 실제 판매용은 대표 이미지·제품 전체·특징 상세·크기/규격 자료와 사용 권한이 필요하다. 참고 사진뿐이면 한계를 밝히고 재질·치수·제조·효능을 추측해 쓰지 않는다.

## 포트폴리오: 분야마다 관찰 순서를 정한다

공통 확대/맞춤/오류 복구 도구는 유지하면서 설명과 전체·세부 보기의 이름·배치를 작업에 맞춘다. 분야가 바뀌면 이전 설명이나 선택 상태가 남지 않도록 초기화한다.

| 분야 | 먼저 보여줄 것 | 이어서 확인할 것 | 자료가 부족할 때 |
|---|---|---|---|
| 웹·제품 UI | 전체 정보 계층 | 검색·목록·상태 등 보이는 구역의 관계 | 원본 화면·상태별 캡처 필요. 정적 시안뿐이면 동작하는 제품이나 검증된 사용성으로 표현하지 않는다 |
| 편집 | 표지/펼침과 페이지의 관계 | 글자 크기·본문 폭·행간·여백 | 실제 펼침/세부 필요. 단일 지면이면 없는 페이지 넘김·인쇄 사양을 만들지 않는다 |
| 아이덴티티 | 이름과 기본 형태 | 간격·획·제공된 색과 적용물 | 벡터·실제 목업 필요. 워드마크뿐이면 가짜 패키지/간판 실적 대신 글자와 색면을 살핀다 |

상세는 분야별 제목만 바꾸는 동일한 긴 카드 나열보다, 자료를 읽는 데 도움이 되는 하나의 도해·짧은 관찰 설명·해당 원본으로 가는 행동을 선택한다. 도해가 실제 제품 인터랙션으로 오인되지 않게 구분한다. 원본 이미지는 왜곡/무리한 크롭 없이 확대 가능하게 둔다. 추가 사진·라이브러리를 필수로 요구하지 않는다.

감상이 목적인 상세에서는 원본과 확대 도구를 먼저 둔다. 관찰 설명은 아래의 보조 정보로 편집해 모바일 첫 화면을 설명 카드가 차지하지 않도록 한다. 별도의 해설·교육 목적이면 설명 우선도 가능하다. 분야별 차이를 주려고 정보량부터 늘리지 않는다.

## 검토

DESIGN.md에 사진 역할/초점 좌표, 분야별 관찰 순서, 확보/부족 자료를 기록한다. 목록 필터 후 크롭, 대표 링크→상세→초점 복귀, 전체/세부→다음 작업 상태 초기화, 이미지 실패→재시도를 확인한다. 자동 검사 외에 원본과 모바일/중간 폭을 직접 본다. 개선 시안은 원본을 보존하고 안내 후 수정한 결과임을 명시한다.

## 역할별 에셋과 모바일 안전 영역

대표=대상을 기억하는 장면, 식별=품목/작업 간 차이, 과정=무엇을 하는지, 세부=재료/조판/판단 근거로 구분한다. 한 파일이 여러 역할을 맡아도 되지만 재사용할 때 새 정보가 무엇인지 적는다. 같은 전체 사진을 되풀이해 긴 페이지를 만들지 않는다.

ASSETS.template.json의 역할 연결·촬영군·피사체·안전 크롭·자료 부재 대안을 사용한다. 모바일 초점은 백분율만 쓰지 말고 ‘컵 손잡이와 손 / 펼친 책의 양면 / 공간 진입부’처럼 남길 대상을 적는다. 크롭으로 보존할 수 없으면 비율이나 배치를 바꾼다. 촬영군이 다른 이미지를 필터로 억지 통일하지 않는다.

브랜드에는 사용 장면/품목 식별/소재, 로컬에는 공간/손·도구/과정, 식당에는 실제 메뉴/테이블, 포트폴리오에는 전체/제공된 세부/역할, 전문 서비스에는 익명 문서 또는 명시한 개념 산출물, 행사에는 원문 날짜/포스터/프로그램 자료를 검토한다. 최소 사진 개수나 유료 에셋 구매를 요구하지 않는다. 실제 자료가 없으면 참고/개념을 표시하고 짧은 구성·의미 있는 아이콘·읽을 수 있는 예시로 대체한다.
