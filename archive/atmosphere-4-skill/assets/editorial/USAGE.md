# 구도·에셋·상태 연결 예제

index.html을 파일로 열거나 기존 정적 서버로 제공한다. 별도 설치·계정·환경 변수·CDN이 없다. 동봉한 사진은 참고 자료이며 실제 상품·매장·운영 수업이 아니다. ASSETS.json에 출처와 이용 조건을 기록했다.

## 필요한 관계만 적용한다

| 예제 | 가져올 부분 | 프로젝트에서 다시 결정할 부분 |
|---|---|---|
| #brand | 같은 사진의 크롭 비교·가까운 캡션/원본 행동 | 상품/음식의 실제 피사체·표시 비율·모바일 초점 |
| #local | 과정 사진 옆 수업 목록·선택/폼/합계 즉시 동기화 | 실제 수업 차이·사진 역할·금액·신청 연동 |
| #portfolio | 대표/보조 위계·모바일 재편집·동등 목록·원본 전체 | 작품·관찰 세부·프로젝트에서 지정한 구도·카드 정렬 계약 |
| #professional | 읽을 수 있는 결과 문서·요청→산출물·모바일 세로 단계 | 실제 제공 범위·문서 내용·자료의 사실 여부 |
| #event | 의미별 일정/금액 묶음·처음 열린 details의 왕복 | 실제 행사 정보·포스터·참가/결제 흐름 |

HTML의 해당 section과 CSS의 관련 선택자·반응형 규칙, JS의 해당 이벤트만 가져온다. 전체 body 테마·모든 예제·샘플 색을 제품 템플릿으로 복사하지 않는다. 기존 컴포넌트/모션 체계가 있으면 같은 역할을 그 방식으로 구현한다. 도식과 SVG 전체 원본은 contain으로 표시하며 실제 프로젝트에 없는 세부/성과를 생성해 사실처럼 채우지 않는다.

SaaS는 이 페이지의 대표 장면을 앱에 넣지 않고 기존 [컨트롤/누름 예제](../motion/contextual.html)를 적용한다. 식당은 #brand의 사진/캡션 관계만 선택적으로 사용하며 메뉴 구분·가격 축·예약의 색상 역할을 유지한다. 사진마다 hover를 추가할 필요는 없다.

## 모션 레이어

- 작품의 바깥 scene-enter는 등장/구도 전환, 안쪽 work-frame은 자세 정돈을 담당한다. 하나의 transform을 서로 덮어쓰지 않는다. CSS transition은 빠른 hover 왕복에서 현재 자세로 이어진다.
- 수업 선택과 금액은 즉시 바뀌고 합계 배경만380ms 동안 강조된다. 재선택 시 이전 강조를 취소한다.
- 요청/산출물 재생은420/620ms, 시차70ms의 예시다. 내용은 기본 HTML에서 보이며 초점을 기다리게 하지 않는다.
- 일정의 시간/제목은 고정하고 열림 표식만240ms 회전한다. 처음 열린 항목의 닫힘/복구도 검사한다.
- 모션 감소에서는 이동·회전 전환을 생략하고 실행 중 애니메이션을 취소한다. 정적 크롭은 사진의 편집 상태로 유지한다. 터치에서 작품 상세는 탭으로 열리고 닫기/Escape 후 원래 버튼으로 초점이 돌아온다.

예제 수치·그리드 비율은 시작값이다. 배포 결과에서 대상과 문구에 맞게 조정하고 [모바일 검토](../../references/mobile-review.md)를 적용한다. JS 비활성 시 콘텐츠와 native 일정 설명은 남고 스크립트 의존 조작은 비활성이다. 실제 예약·문의·결제 기능은 포함하지 않는다.
