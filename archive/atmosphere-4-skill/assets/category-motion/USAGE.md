# 콘텐츠별 모션과 정렬 검토

`index.html`을 HTTP 서버에서 연다. 기존 프로젝트에는 필요한 section/CSS/이벤트만 옮기고 에셋 경로·문구·값을 실제 자료로 바꾼다. `examples.js`의 전체 이벤트를 필요 없는 페이지에 붙이지 않는다. 배색·간격은 전역 테마가 아니다. 서버·의존성·유료 계정을 자동 설치하지 않는다.

| 관계 | 실제 바뀌는 것 | 시작값·고정할 것 |
|---|---|---|
| 업무 | 상태 즉시 변경 | 표식 opacity150ms, 행/열 고정 |
| 브랜드 | 같은 사진 상세·원래 초점 | 사진1.035/560ms, 상세6px/220ms; 클릭 즉시 |
| 로컬 | 수업·금액 요약 즉시 변경 | 요약3px/260ms, 목록 고정 |
| 식당 | 분류·결과 수 즉시 변경 | 결과 수 opacity150ms, 이름/가격 고정 |
| 포트폴리오 | 자세 정돈·같은 작품 상세 | 대표660ms, 모바일 회전 제거, 원본contain |
| 전문 서비스 | 결과의 핵심 판단 | 요약3px/260ms, 문서 전체 부유 없음 |
| 행사 | 처음 열린 설명의 닫힘/열림 | native details 즉시, 표식240ms |

시간·거리는 예시다. 새 입력은 이전 장식을 취소하고 마지막 상태가 남는다. JS/모션 실패 시 초기 핵심 콘텐츠는 기본 표시된다. 빠른 출입·선택 왕복·상세 중 Escape·초점 복귀·실행 중 모션 감소 변경·터치를 실제 확인한다. 상세는 실제 shared-element 전환이 아니라 즉시 native dialog+짧은 내용 등장이다.

## 그룹 전체와 내부

`scripts/layout-probes.js`의 `measureGroups`에 anchor/group/icon/text selector를 준다. 수평 배치는 center/start/end, 수직은 center 또는 first-line을 선택한다. 첫 줄은 실제 첫 글리프 상자이므로 서체의 광학적 차이는 실제 화면으로 해석한다. 전체 그룹 가로 배치와 내부 세로 차이를 각각 남긴다. 누락/복수 대상은 미측정이다.

## 확대 검토

상단 선택은 예제 영역의 원래 computed 글자 크기, 선택적으로 행간을2배로 주입한다. 기본으로 복구 가능하며 브라우저 메뉴 확대와 다르다. `measureTextBounds`의 문서 넘침과 내부 후보를 실제 화면으로 확인한다. 고정 높이의 줄 겹침/선택값/가격/대화상자도 따로 본다. 도구는 자동 미적 판정이나 접근성 인증이 아니다.

사진은 기존 cup.jpg 참고 사진을 재사용하고 작업물은 기존 editorial.svg 개념 자료다. 새로운 실물/촬영군을 확보한 예제가 아니며 출처는 `ASSETS.json`과 원본 묶음에서 확인한다. 원형 배지나 얕은 사진은 모든 카테고리의 기본값으로 복사하지 않는다.
