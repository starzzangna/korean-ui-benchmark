# 개념 장면 컴포넌트 사용

[plan-board.html](plan-board.html)은 실제 자료가 없는 전문 서비스의 과정을 개념 문서로 보여주는 실행 예제다. 외부 이미지·CDN·유료 서비스 없이 열 수 있다. HTTP 정적 서버에서 이 폴더와 상위 fonts/motion 경로를 함께 제공한다.

선택한 `.ks-board` 마크업과 `scene.css`만 프로젝트에 가져오고, 움직임을 사용하면 [motion.css/js](../motion/USAGE.md)를 연결해 해당 장면에 mount한다. 전체 예제의 body 스타일·고정색·문구를 브랜드 템플릿으로 복사하지 않는다. 기존 스타일 시스템에서는 같은 구조를 그 프로젝트의 컴포넌트로 표현해도 된다.

- `--scene-ink/paper/line/back/back-secondary/note/muted`를 프로젝트 색의 역할에 맞춘다.
- `ks-board--landscape`는 짧은 내용을 가로 문서로 편집하는 선택 모드다. 긴 설명을 억지로 세 열에 넣지 말고 원래 세로형이나 실제 내용에 맞는 형태로 바꾼다.
- 앞뒤 종이와 작은 캡션은 과정을 읽게 하는 만큼만 사용한다. 새 자료에 맞지 않으면 레이어를 줄인다.
- 가운데 문서는 실제 텍스트이며 화면 읽기·확대에 대응한다. 뒤 장식과 반복 캡션은 aria-hidden으로 의미 중복을 줄인다.
- 실제 서비스의 목표·범위·결과물로 내용을 교체하고 개념 미리보기임을 표시한다. 가짜 실적·검수 표시·고객명으로 만들지 않는다.
- 320/390/768/1440px, 큰 글자, 모션 감소, 키보드에서 검토한다. 내용이 늘면 모바일에서 레이어를 펼치고 의미 있는 글자를 숨기지 않는다.

이 컴포넌트는 화면의 한 장면이다. 서비스 선택·문의 폼·사진·작품 탐색을 대체하지 않는다.
