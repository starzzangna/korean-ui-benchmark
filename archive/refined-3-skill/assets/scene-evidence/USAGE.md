# 연결과 실제 화면 확인 예제

index.html을 HTTP 서버에서 연다. 별도 설치/API키/CDN은 없으며 기존 프로젝트 서버를 재사용한다. 이 디렉터리만 복사하면 상대 이미지/폰트/검사 모듈이 끊기므로 사용할 이미지와 권리 기록, CSS/JS 및 ../../scripts/layout-probes.js의 필요한 부분도 함께 조정한다.

- 사진: 참고 장면→같은 자료 상세→닫기/원래 초점, 관심 개수 즉시 반영과 짧은 피드백.
- 로컬: 과정 사진과 수업 차이/가격/선택, 선택 요약의 동일 대상 즉시 반영.
- 작품:2열/3열의 실제 프레임 크기 비교, 짧은 목록과 목표/관찰을 가진 같은 원본 상세. 모바일은 같은 축을 유지한1열이다.
- 일정: 열린 설명→표식45도, 닫힘/복귀. 폰트 문자 대신 여유 있는 SVG 선 도형을 사용하지만 기본·열림·회전 중·두 확대 방식에서 범위 검사는 유지한다.

모션은 이미지 약1.02배/화살표3px와 상태300ms 감속의 예다. 고정 세트가 아니며 장식 때문에 데이터/상세를 지연하지 않는다. 새 선택은 이전 장식을 취소한다. 감소 모션은 애니메이션을 취소하고 열린 표식의 정적 상태는 남긴다. hover 없는 터치·키보드에서 같은 정보와 행동에 접근한다.

글자만/글자행간2배 버튼은 computed 값 주입이며 실제 브라우저 메뉴 확대가 아니다. 원래 글자 버튼은 원래 인라인 값을 복구한다. 현재 표식 검사는 지정 대상의 가로 상자/문자 범위를 확인할 뿐 접근성·전체 시각 품질 인증이 아니다. 최종 프로젝트에서 실제 메뉴 확대/오류/가장 긴 자료/모달도 검사한다.

색·구도·비율 전체를 복사하지 말고 해당 관계만 사용한다. 사진을 실제 판매 제품/매장 증거로 바꾸지 않으며 작품은 개념 자료로 표시한다. DESIGN에는 실제 적용 위치·상태·PC/모바일 화면과 미충족/대체 이유를 남긴다.
