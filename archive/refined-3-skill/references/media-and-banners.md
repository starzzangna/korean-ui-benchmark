# 이미지 탐색과 메인 배너

## 포트폴리오·이미지 목록

첫 화면의 목적과 작품 편집은 [portfolio-composition.md](portfolio-composition.md)에서 먼저 결정한다. 아래 내용은 선택한 구도에서 실제 상세 탐색을 완성하는 기준이다. 대표 작품을 먼저 보여주는 소개형과 목록/감상 중심을 구분한다.

작업의 이름·분야·형태를 먼저 식별하고 더 자세히 볼 수 있어야 한다. 큰 목업이 제목을 화면 아래로 밀어내면 모바일에서 캡션을 이미지 앞에 두거나 비율을 조절한다. 작은 썸네일의 텍스트를 읽어야만 작업을 이해하는 구성은 피한다.

DESIGN.md에 다음 흐름을 실제 기능으로 확정한다.

- 목록에서 클릭할 수 있는 범위를 명확히 하고, 작업명·분야·상세 보기 의도를 보인다. hover 표현은 키보드 focus에서도 대응하며 터치에는 hover 없이 같은 정보·행동을 제공한다.
- 상세에서는 설명만 반복하지 않고 충분히 큰 작업 이미지를 제공한다. 실제 확보한 원본 해상도에 맞춰 전체·세부 보기를 선택한다. 모형 작업은 콘셉트임을 유지하고 실제 의뢰·성과를 만들지 않는다.
- 이미지에 맞춤/확대/축소가 필요하면 최소·최대 배율과 이동 방법을 정한다. 확대 상태의 스크롤·키보드·터치가 가능해야 하며 페이지 확대를 가로채지 않는다. 단순히 큰 이미지를 보는 과업이면 복잡한 제스처 구현은 생략할 수 있다.
- 여러 이미지나 작업을 넘길 때 현재 위치와 경계를 알리고, 작업/이미지 변경 시 배율·스크롤을 초기화한다. 목록 필터가 있으면 상세의 이동 범위를 필터 결과와 일치시킨다.
- 닫기·Escape·초점 복귀, 이미지 로딩·실패·재시도와 원래 입력 보존을 구현한다. 불러오지 못한 이미지는 빈 공간으로 방치하지 않는다.

모션은 확대 가능성·전환·선택을 설명할 때만 사용한다. 이미지의 가벼운 크기 변화나 초점 강조도 충분할 수 있다. 기울임·패럴랙스·자동 슬라이드를 기본으로 강제하지 않는다. reduced-motion에서는 불필요한 이동을 줄이고 같은 정보를 제공한다.

## 행사 메인 배너

행사명·일시·참가/프로그램 행동과 핵심 시각 요소가 하나의 구도로 읽혀야 한다. ‘텍스트 왼쪽 + 별도 포스터 오른쪽’을 자동 기본값으로 삼지 않는다. 확보한 자료에 따라 날짜 중심 조판, 전체 면 포스터, 실제 사진 중심 중 적합한 구도를 검토한다. 기존 브랜드 구도가 있으면 우선한다.

DESIGN.md에 행사명·날짜·제목·CTA·시각 요소의 관계, 첫 화면의 주인공, 모바일 읽기 순서를 기록한다. 그래픽이 날짜나 두 일정의 관계를 나타내면 그 역할을 설명하고 핵심 날짜는 실제 읽을 수 있는 텍스트로 제공한다. 포스터의 문자와 소개를 같은 말로 두 번 크게 반복하지 않는다.

모바일은 데스크톱의 축소판이 아니다. 소개 뒤에 큰 포스터가 다시 쌓여 시간표가 과하게 밀리면 날짜·제목·행동을 먼저 보이고 보조 그래픽을 축소·재배치하거나 생략한다. 고정 높이를 줄이는 것만으로 글자를 자르지 않는다. 실장소·발표자·잔여석·긴급성을 자료 없이 만들지 않는다.

## 확인 기준

1. 목록 → 큰 이미지 → 세부 보기/다음 작업 → 닫기 흐름을 마우스·키보드로 수행한다. 필터 후 이동, 최대/최소 배율, 로딩 실패 후 재시도도 확인한다.
2. 390·768·1440px에서 캡션·이미지 비율·확대 조작·배너의 정보 위계를 직접 본다. 작은 화면에서도 본문·초점·닫기 버튼이 가려지지 않아야 한다.
3. 행사명·날짜·가격 또는 참가 조건·시간표로 이동하는 행동을 찾을 수 있는지 확인한다. 제목의 문서 y 좌표와 사람의 이해 속도를 같은 결과로 취급하지 않는다.
4. 기능 통과와 미적 선호를 나눠 기록한다. 기존 동결 비교본은 보존하고 사후 개선을 최초 제작 MD 효과로 합산하지 않는다.

## 긴 상세를 모달로 표시할 때

둥근 외곽에서 기본 스크롤이 모서리를 가리지 않도록 [모달 외곽/본문 분리](dialog-scroll.md)를 적용한다. 외곽의 overflow:hidden은 실제 스크롤 가능한 내부 본문과 함께 사용하며 내용을 잘라 통과시키지 않는다. 투명 레일·얇은 둥근 손잡이는 상세 영역에 한정하고 닫기·최하단 행동·확대 이미지 이동을 함께 검토한다. 기존 모달 라이브러리의 초점 관리는 유지한다.
