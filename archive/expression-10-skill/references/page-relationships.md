# 페이지 관계와 구현 검증

## 편집 선택을 실제 구현으로 연결하기

첫 화면·비교 구간·완료 구간을 나란히 축소해 보고 각 구간의 대상, 새로운 정보, 다음 행동을 한 줄씩 적는다. 새 정보가 없는 큰 로고·가격표 모양의 장식·같은 집계는 제거하거나 실제 탐색 행동으로 바꾼다. 간결한 업무 화면에는 장식용 진행 요약이나 마감 패널을 자동 추가하지 않는다.

색은 구간마다 새 테마를 만드는 대신 바탕·내용·선택·오류 역할을 이어 쓴다. 큰 색면을 낮출 때도 조작 경계와 초점 대비는 별도로 유지한다. 업종별 고정 색과 면적 비율을 강제하지 않는다.

사진 후보는 피사체 식별, 모바일 크롭, 문구 안전 영역, 다음 행동과의 관계로 선택한다. 식당은 식사·공간·메뉴 중 무엇을 판단하게 하는지 명확히 하고 무관한 디저트 사진으로 식사를 대표하지 않는다. 참고 사진은 실제 제품/장소 사진으로 표시하지 않는다. 외부 사진은 파일별 출처·작가·라이선스·변경 내용을 기록하고 필요한 공개 표기를 실제 화면에 넣는다.

## 정렬은 요소 목록보다 사용자 흐름으로 찾기

내비게이션→필터→카드→상세→완료의 모든 보이는 조작을 훑는다. 공통 컴포넌트 밖의 텍스트 링크·문자 화살표도 포함한다. 긴 문구는 줄바꿈을 허용하되 화살표는 별도 비축소 요소로 만들고 묶음을 inline-flex로 정렬한다. nowrap이나 overflow:hidden으로 손실을 숨기지 않는다.

동등한 카드가 홀수일 때 마지막 행의 빈 공간도 검토한다. 넓은 화면의 동일 3열, 자료 크기가 필요한 중간 폭의 한 열/행 배치처럼 읽는 목적에 맞는 대안을 선택한다. 필터 결과가 0·1·전체일 때 폭과 읽는 순서를 다시 확인한다. 카드의 바깥 폭만 맞추고 이미지·캡션·행동 축의 차이를 방치하지 않는다.

## 모션 선택과 검사

실제 탐색 대상에만 이동 피드백을 준다. 작품 열기에는 프레임의 작은 translate와 이미지의 완만한 scale, 수업 선택에는 화살표 이동, 문의에는 다음 방향의 표식 이동을 선택할 수 있다. 정적인 참고 사진이나 정보용 메뉴를 클릭 가능한 것처럼 움직이지 않는다. 등장 효과만 구현하고 실제 탐색 동작을 빠뜨리지 않는다. 이동량과 효과 개수를 품질 점수로 삼지 않는다.

[실행 예제](../assets/flow-review/index.html)는 긴 문구/화살표, 동등한 카드, 상태별 이동을 함께 제공한다. 색과 배치를 통째로 복사하지 않고 필요한 관계만 사용한다.

## 완료 증거

- 320·390·768·1440px에서 첫 화면뿐 아니라 중간·하단을 캡처한다. 대표 사진의 식별과 구간별 색 연결을 직접 확인한다.
- 글꼴 로드 뒤 글자만 200%와 글자/행간 200%를 분리 검사한다. font-only에서 기존 px 행간을 고정하지 않는다. 회전 아이콘·일반 텍스트 화살표·오류·열린 상세의 내부 잘림과 마지막 행동까지 확인한다.
- 모션 감소, 키보드 초점, 터치, 빠른 왕복에서도 정보와 즉시 상태 갱신을 보장한다. transition:all과 레이아웃 전체 이동을 피한다.
- DESIGN.md의 선택마다 최종 선택자·화면 폭/상태·관찰 결과를 남긴다. 선언한 선택자만 검사하지 말고 실제 보이는 조작 목록과 대조해 누락을 찾는다. 정상 기능, 계측 통과, 미적 선호는 별도로 기록한다.

장식용 로고/포스터 문자를 그래픽으로 취급하려면 크기 변화와 무관한 벡터 형태를 사용할 수 있다. 의미는 별도의 실제 제목으로 전달하고 장식 SVG는 aria-hidden으로 구분한다. 본문·가격·조작 문구를 그림으로 바꾸어 확대 검사를 피하지 않는다. SVG text가 고정 viewBox 안에서 커질 때는 문서 넘침과 별개로 그림 내부를 확인한다.

## 표현 변경 뒤 최종 변형 검토

부분 스타일을 바꿀 때는 부모 배경·gap·자식 면·모서리까지 합성된 결과를 확인한다. 색면을 지웠어도 남은 부모 배경이 간격에 드러날 수 있다. flex 방향을 바꾸면 기존 flex-basis·자동 margin·자식 최소 크기가 새 축에서 빈 공간이나 치우침을 만드는지도 확인한다. 설명 옆 사진을 구분하는 데 별도 배경 면이 필요한지 콘텐츠로 판단한다.

밑줄/텍스트 버튼을 채움형으로 바꾸면 배경만 바꾸지 않는다. 최소 조작 높이·좌우 내부 여백·문구/표식 전체 중앙·줄바꿈·기본/선택/초점/비활성·모션 감소를 같은 변형으로 완성한다. 내부 아이콘 중앙만 맞고 전체 묶음이 한쪽으로 치우치지 않는지 본다.

중간 폭에서는 제목·설명·가격·행동의 묶음을 명시적으로 재배치한다. 자동 grid 배치와 일부 행 점유를 섞어 제목과 가격을 다른 맥락에 놓지 않는다. 문서 넘침 없음과 그룹 내부 좌표 통과는 정보 묶음의 완성 판정이 아니다. 필터 0·1·전체 및 긴 문구/확대에서도 실제 순서를 본다.

첫 화면은 자료의 큰 크기뿐 아니라 소개·대표 자료·첫 행동의 관계를 검토한다. 주요 PC 높이에서 대표 자료의 핵심과 상세 행동이 어떻게 노출되는지 확인하고, 충분한 원본 감상은 상세로 연결할 수 있다. 고정100vh·글자 축소·모든 자료의 한 화면 수용을 강제하지 않는다.

연속 구간은 컨테이너·공통 열·간격의 위계를 먼저 정한다. 제목의 열과 목록의 임의 퍼센트 들여쓰기를 따로 조정하지 말고 같은 그리드나 명시적 정렬 축으로 연결한다. 큰 빈 영역은 날짜/분류 등 실제 역할이 있을 때 유지한다. 목록 밀도는 동일한 열림/필터 상태에서 비교한다. 검증한 장점의 보존 범위를 지정하고 영향을 받지 않아야 할 구간의 DOM/스타일/화면도 대조한다.
