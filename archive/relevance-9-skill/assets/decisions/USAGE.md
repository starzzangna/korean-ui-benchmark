# 편집 선택·상세 복귀·확대 대응

index.html은 설치/CDN/API키 없이 정적 서버 또는 파일로 실행한다. 기존 editorial 예제는 유지하며 이 예제의 필요한 관계만 가져온다. 선택 버튼 자체를 최종 제품의 설정 UI로 복사할 필요는 없다.

| 블록 | 실제 제공 | 다시 결정할 것 |
|---|---|---|
| #photo | 같은 사진에서 사진 우선/소개 병치 비교, 띄어쓰기 보존 | 실제 피사체·사진군·소개 면적·행동·모바일 크롭 |
| #works | 동등한2열/7:4 예시·마지막 동일 폭·긴 설명·필터 빈 결과 복구·상세 초점 복귀 | 작품 수·대표/세부·다음 섹션 간격·원본 확대 탐색 |
| #service | 한 요청/한 판단과 읽을 수 있는 상세 문서 | 실제 제공 범위·자료의 사실 여부·어디까지 첫 화면에 노출할지 |
| #event | 영문보다 한국어 행사명/일정, 짧은 option+외부 전체 조건·합계 즉시 갱신 | 실제 포스터·브랜드색·참가 규칙·오류/전송 흐름 |

사진 파일과 개념 SVG는 기존 동봉 자료를 상대 경로로 사용한다. ASSETS.json은 출처·역할·촬영군 검토와 모바일 대안을 기록한다. 실제 상품/장소/고객/행사 증거가 아니다. 사진을 추가 확보한 것처럼 보고하지 않는다.

## 모션의 범위

작품 선택은 이름과 같은 자료를 즉시 native dialog에 표시한다. 6px/180ms 진입은 장식이며 진짜 shared-element 전환이 아니다. 열기 중 닫기·재열기에서 기존 애니메이션을 취소하고 필터와 발신 버튼 초점을 유지한다. 이미지 실패/재시도도 제공한다. 원본 확대·이전/다음·터치 이동은 이 작은 예제의 범위 밖이며 실제 포트폴리오에서는 요구된 탐색 기능을 유지한다.

선택값/금액은 즉시 반영하고 합계 위치의 색만360ms 강조한다. 화살표는280ms로 이동하며 정적 문서에는 클릭을 암시하는 hover를 주지 않는다. 사진 배치 전환은 즉시 비교하며 전체 목록을 이동시키지 않는다. 숫자는 시작값이다. 실행 중 모션 감소 설정이 켜지면 진행 애니메이션을 취소하고 정적 내용을 남긴다. hover 없이도 실제 버튼으로 상세/선택을 사용한다.

## 검토

320/390/768/1440과 레이아웃 전환 폭에서 첫 화면·중단·다음 구간을 본다. 작업 필터 전체→1개→0개→복구, 상세 닫기/Escape/Tab·재열기·이미지 실패/재시도, 참가 가장 긴 option+4명·외부 요약·금액을 실제 조작한다. 글자200%에서 select는 여러 줄을 기대하지 않고 연결된 전체 조건이 남는지 확인한다. JS 비활성에서는 자료가 표시되고 스크립트 의존 버튼/선택은 비활성이다. 실기기/Safari/스크린리더 인증은 별도다.
