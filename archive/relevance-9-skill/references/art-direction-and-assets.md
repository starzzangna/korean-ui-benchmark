# 표현과 실제 자료를 함께 선택하기

목록·가격·다음 행동을 명료하게 보여주고, 브랜드·전문 서비스의 인상이 중요하면 사진과 실제 산출물로 식별 가능한 장면을 만든다. **대상 식별 → 장면의 기억 → 선택/행동**을 연결한다. 빠른 정보 탐색이 목적인 화면에는 긴 장면 구성을 강제하지 않는다. 색만 바꾼 복수 안이나 장식 개수를 목표로 삼지 않는다.

| 카테고리 | 서로 다른 표현 후보 | 표현에 필요한 에셋 | 모바일 편집과 확인 |
|---|---|---|---|
| SaaS 업무 | 정렬된 업무대 / 처리 대기열 / 분석+근거 목록 | 실제 상태·기한·담당 데이터, 빈/실패 상태; 마케팅 사진 불필요 | 제목·상태·다음 행동 우선. 긴 목록과 지표의 의미를 보존 |
| SaaS 소개 | 실행 가능한 한 과업 / 큰 제품 장면과 설명 / 기술 입출력 | 실제 제품 UI 또는 명시한 작동 데모, 입력·결과 | 전체 대시보드를 작게 축소하는 대신 읽을 수 있는 핵심 장면 |

| 포트폴리오 | 작업 하나를 크게 / 콜라주+인덱스 / 편집형 시리즈 | 전체·세부 원본, 역할/범위/매체, 실제 작업 순서 | 축소 썸네일에서 끝내지 않고 상세·실제 확대·다음 작업. 첫 화면 콜라주와 목록이 같은 정보를 중복하는지 확인 |

개수는 필요 장면의 목록이지 사진 최소 할당량이 아니다. 대표 장면·목록·상세에 서로 다른 정보가 있는지 먼저 본다. 한 장뿐이라면 같은 사진을 반복해 긴 페이지를 만들지 않는다. 캠페인 자료가 충분하면 목록을 무조건 첫 화면에 압축할 필요도 없다.

## 표현을 구체화하는 짧은 결정

DESIGN.md에 다음을 적고 바로 대표 화면을 만든다.

- **장면:** 무엇을 얼마만큼 크게 보여주는가? 예: 손으로 흙을 다듬는 근접 사진과 완성 그릇의 전체 모습.
- **편집:** 사진의 거리·크기 차이, 제목과 사진의 관계, 정렬 축 중 이번 사이트의 규칙은 무엇인가?
- **근거:** 사용 가능한 실제 파일은 무엇이며 어떤 장면이 아직 없는가?
- **행동:** 대표 장면에서 상품·가격·예약·작업 상세로 어떻게 이동하는가?
- **모바일:** 무엇을 재크롭·재배치하고 무엇을 생략하는가? 고정 높이 대신 내용 높이로 확인한다.

자료가 없는 상태에서 구도를 확정한 뒤 비슷한 스톡 사진을 끼워 맞추지 않는다. 식별 가능한 원본·구체적인 내용·촬영 방향이 구성 선택의 입력이다. 부족한 자료는 [에셋 제작 요청서](../assets/ASSET-BRIEF.md)에 작업 가능한 요청으로 남긴다. 파일이 존재하고 권리가 확인됐다는 검사와, 그 파일이 이 브랜드의 판단 근거가 되는지는 별도로 검토한다.

고급 느낌을 작은 회색 라벨·큰 빈 공간·기울어진 종이·궤도 도형으로 대체하지 않는다. 이 요소 자체를 금지하는 것도 아니다. 다른 브랜드의 이름을 넣어도 아무 변화가 없다면 실제 대상·촬영·조판 중 하나를 다시 결정한다. 서로 다른 구역을 억지로 전부 다르게 만드는 것보다 내용과 반복 리듬이 중요하다.

## 조건에 맞는 표현만 적용하기

업종과 보유 자료에 맞춰 사진의 거리 변화·실제 UI·한국어 조판·행동 문구를 선택하고 실제 화면에서 검토한다. 화면 높이·사진 수·캡션 유무는 콘텐츠로 결정한다. 색·CDN·라이브러리는 기존 브랜드와 실행 환경에 맞추며, 허구의 후기·성과·긴급성으로 빈 자료를 채우지 않는다. 선택하지 않은 표현이나 설치하지 않은 도구를 적용했다고 보고하지 않는다.

## 자료를 고른 뒤 정하는 구도

에셋마다 주인공/비교/세부/결과 중 맡을 판단을 지정한다. 분위기 사진과 실제 제품·수업·성과 증거를 나눈다. 실제 사용 폭에서 식별되는 대상 크기와 문구 안전 영역을 확인하고, 자료의 빛·색·질감·거리로 주변 조판과 바탕을 결정한다. 부족한 원본을 장식이나 가짜 결과로 채우지 않는다. 현재 자료의 다른 크롭이나 원문 조판으로 목적을 달성할 수 있는지도 기록한다.

작품 두 개의 병치는 작업 범위를, 한 작품의 큰 세부는 특정 관점을 보여줄 때 채택한다. 이미지 상자 크기 차이만 만들지 말고 어떤 작업을 먼저 읽는지와 실제 캡션·탐색을 연결한다.
