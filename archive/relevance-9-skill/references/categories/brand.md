# 브랜드 · 대상 식별과 상품 탐색

## 종이·제품과 바탕의 관계

종이·패키지·사용 사진의 빛에서 페이지 바탕과 상품 감상 면을 선택한다. 대표의 분위기 면과 품목을 비교할 면은 명도·온도·간격으로 연결할 수 있다. 흰 바탕을 자동 상속하거나 모든 브랜드를 같은 미색으로 만들지 않는다. 상품 원본에 색 필터를 씌우지 않고 제목·가격·관심 행동의 대비를 유지한다.

## 상품을 감상할 크기와 탐색의 역할

상품의 형태·소재가 선택 근거면 작은 썸네일 행으로 압축하기 전에 실제 감상 면적을 정한다. 대표 품목과 보조 품목의 대비, 동등한 카탈로그, 쓰임 중심 편집 중 보유 자료와 구매 판단에 맞는 관계를 선택한다. 특정 열 수·대표 상품 할당량은 고정하지 않는다. 브랜드 사진이 분위기만 맡으면 상품 식별 자료는 별도로 충분히 보여준다.

품목 색인·검색·분류·상품 목록이 같은 정보를 반복하는지 확인한다. 분류를 고르는 색인은 실제 분류값과 보이는 상품을 갱신하고 해당 상품의 상세/관심 행동까지 연결한다. 모바일에서 긴 색인을 지나 다시 같은 목록을 시작하게 만들지 않는다. 박스 반경이나 배경을 바꾸기 전에 상품 자체의 크기·크롭·제목/가격의 위계를 검토한다.

## 목적과 구성 선택

브랜드 메시지·상품 사용 장면·탐색 행동을 함께 이해해야 하고 사진 옆에서도 피사체가 식별되면 비대칭 병치를 검토한다. 전면 사진은 큰 면적이 실제 사용 맥락을 더 잘 전달할 때 선택한다. 사진 중심이라는 요구를 모든 첫 섹션의 전폭 사진으로 해석하지 않는다. 구체적인 선택은 [첫 화면 기준](../hero-composition.md)을 따른다.

브랜드 인상을 먼저 전달하면 캠페인/사용 장면, 재료와 제작을 설명하면 저널, 품목 비교가 우선이면 컬렉션/상품 색인을 검토한다. 사진·문구·행동을 같은 대상에 연결한다. 관심 저장·검색·상세 중 현재 목적의 주행동을 정하고 모든 조작을 같은 강도로 강조하지 않는다.

## 자료와 설명 밀도

사용 장면·품목 식별·소재 세부의 역할을 구분한다. 목록은 이름·가격·구별할 특징을 우선하고 긴 소재/제작 설명은 실제 상세로 연결한다. 각 사진의 빛·거리·색온도·크롭·피사체 면적을 비교한다. 참고 사진을 판매 상품의 직접 증거처럼 표시하지 않는다.

브랜드와 실제 사진에서 배색을 정하고 행동/선택/오류의 역할을 유지한다. 하단 로고의 크기는 식별·탐색·마무리 역할로 결정하며, 새 정보 없이 큰 면적을 차지하면 줄이거나 생략한다. 부드러운 인상이 필요하면 사진의 바깥 프레임을 조정하되 원본·캡션·초점 링은 자르지 않는다.

## 조작과 모션

클릭 가능한 사진의 반응은 동일 상품 상세나 컬렉션으로 연결한다. [상품 예제](../../assets/category-motion/index.html#brand)처럼 관심 상태/개수는 즉시 바꾸고 장식은 결과를 지연하지 않는다. 비조작 사진에는 클릭 신호를 강제하지 않는다.

## 구현과 검토

동등 비교 목록은 카드 폭·이미지 영역·이름/가격·행동 축을 맞춘 뒤 실제 물건의 시각적 크기를 본다. 편집형 비대칭은 강조할 품목과 순서를 명시한다. 모바일에서 헤더/로고·긴 가격·줄바꿈 제거 후 단어 붙음, 상세 왕복과 초점을 확인한다.

[편집 결정](../editorial-decisions.md) · [자료 준비](../asset-pipeline.md) · [모바일 검토](../mobile-review.md). 선택한 기준은 [적용 확인](../applied-evidence.md)으로 최종 DOM·조작·PC/모바일 화면과 대조한다. 수치상 통과와 실제 읽기/광학 판단, 미실행을 구분한다.


## 컬렉션 툴바와 간격

분류 select·상품 검색·제출/초기화가 나란하면 실제 조작 상자의 높이와 상하 기준선을 맞춘다. 같은 padding/min-height 선언만으로 완료하지 않고 native select와 search의 렌더링 차이를 측정한다. 라벨 간격과 필드 간격을 공유하고 모바일에서는 입력 폭·검색 버튼 문구를 확보하도록 재배치한다. 상품 카드의 이름/가격·행동 축, 결과 건수→목록 간격도 함께 본다. 장식선은 사진보다 낮은 시각적 강도로 두며 입력 경계·포커스와 역할을 분리한다. 자세한 구현은 [컨트롤 정렬](../control-alignment.md)을 따른다.


## 셀렉트 간격의 일관성

선택 컨트롤이 있으면 같은 제품/비교 범위의 화살표 크기·우측 여백·문구 안전 영역을 공통 토큰으로 연결한다. native 기능과 label/검증/값 갱신은 유지한다. [셀렉트 표시 계약](../control-alignment.md#네이티브-선택-기능과-화살표-표시의-공통-계약)에 따라 실제 모바일·글자 확대·키보드와 연결 기능을 확인한다. 셀렉트가 필요 없는 화면에는 새로 추가하지 않는다.

## 장면과 상품 색인의 역할 배분

### 첫 화면의 표현력

브랜드 소개가 목적이면 짧은 제목 다음에 검색/분류를 놓는 것만으로 상단을 완성하지 않는다. 브랜드를 기억하게 할 대표 사진과 핵심 문구, 해당 컬렉션으로 연결되는 행동을 한 장면으로 편집한다. 여백은 피사체·제목의 시선 관계를 만들 때 사용하며 대표 대상이 없는 공간을 간결함으로 판단하지 않는다. 긴 소개와 장식은 덜어도 사진의 존재감까지 덜지 않는다.

전폭 사진+외부 캡션, 사진 위 문구, 큰 사진 아래 제목, 비대칭 편집, 좌우 분할 중 에셋의 구도와 문구 길이에 맞춰 선택한다. 좌우 분할·전면 사진·고정 뷰포트 높이 중 어느 것도 기본값으로 강제하지 않는다. 문구를 겹칠 경우 PC/모바일에서 피사체와 얼굴/손/상품의 식별부를 가리지 않고 실제 배경 위 대비를 확인한다. 공간이 부족하면 문구를 사진 밖으로 이동한다. 안전한 크롭과 문구 영역을 확보하지 못한 사진은 교체하거나 구성을 바꾼다.

검색·분류는 컬렉션 시작에 두고 대표 장면과 역할을 분리한다. 검색 중심 카탈로그라는 명시적 과업일 때만 색인 우선 구성을 선택하고 그 이유를 기록한다. 모바일에서 사진이 장식 조각으로 축소되거나 과도한 높이로 행동이 밀리지 않는지 실제 첫 화면과 한 번의 스크롤을 함께 확인한다.

완료 증거에는 PC/모바일 상단 캡처, 실제 이미지 로드, 핵심 피사체의 크롭, 제목/CTA 대비와 겹침, CTA의 해당 컬렉션 도착을 남긴다. 모션을 사용하면 대표 장면/사진에 작은 translate나 scale을 한정하고 핵심 문구·행동은 즉시 사용할 수 있게 한다. 이미지 실패와 모션 감소 상태에서도 제목·대상 설명·컬렉션 진입이 남아야 한다.

브랜드 인상이 주요 목적이면 상품 식별이 가능한 사용 장면 하나를 첫 구간의 주인공으로 두고 컬렉션으로 바로 연결한다. 구매 탐색이 우선이면 상품 색인이 먼저 나와도 된다. 어느 경우든 소개 문구·분류 라벨·상품 번호·테두리를 모두 같은 강도로 강조하지 않는다. 단순한 목록을 만들었다는 이유로 브랜드 장면까지 충분하다고 판단하지 않는다.

상품 이름/가격/행동을 비교하는 목록에서는 필터1개→빈 결과→전체 복구 후에도 열 폭과 행동 축을 유지한다. 소개 장면의 비대칭을 상품 목록까지 기계적으로 적용하지 않는다. 분류 요구 값별 실제 결과와 검색 결합, 동적 관심 목록을 생성한 뒤 상세/확대/닫기를 [완료 게이트](../delivery-gates.md)로 확인한다.

## 페이지 관계의 구현 확인

대표 사진과 핵심 문구의 존재를 유지하면서 큰 배경 색면의 무게를 조절한다. 사진→상품 비교→관심 목록의 탐색 흐름으로 하단을 연결한다. 큰 브랜드 이름만 반복하지 않는다. 참고 사진과 실제 판매 상품의 관계는 명시한다.

공통 구현과 검토는 [페이지 관계 기준](../page-relationships.md)을 따른다.

## 표현 변형과 정보 묶음의 최종 검토

첫 장면을 수정한 뒤 부모 배경이 gap에 띠처럼 남지 않는지 확인한다. 사진·문구가 이미 분리되어 있으면 별도 문구 면의 필요성을 다시 판단한다. 사진 면적·제목·CTA의 대비를 함께 편집하며 텍스트 링크를 채움형으로 바꿀 때 내부 여백과 상태까지 완성한다.

## 대표 장면에서 상품으로 이어지는 간격

대표 장면 끝과 컬렉션 제목 사이의 실제 간격은 두 섹션의 여백을 합쳐 검토한다. 제품 판단에 새 정보가 없는 보조 구간으로 빈 공간을 채우지 않는다. 사진 감상과 다음 탐색의 호흡을 유지하면서 과도한 공백은 줄이고 PC/중간 폭/모바일에서 제목과 첫 상품 진입을 함께 본다.

## 상단과 본문의 연결 판단

상시 상품 탐색과 캠페인 영역을 구분한다. 종이·상품의 질감이 주인공이면 같은 바탕으로 상단과 카탈로그를 연결하고 조판·간격으로 구간을 나눈다. 캠페인이 달라질 때 배너만 달리할 수도 있다. [공통 선택 기준](../header-and-surfaces.md)을 실제 메뉴 수·자료·방문 과업에 대조한다.

## 탐색 길이와 강조의 편집

상품 수가 적고 탐색이 주요 과업이면 불필요한2행 GNB·소개 문구를 줄인다. 대표 상품의 큰 면적은 소재나 사용 설명을 추가할 때 선택하고, 동등 비교가 목적이면 사진·제목·가격·관심 행동의 축을 맞춘다. 소개/목록의 분류 색인이 중복되면 하나로 정리한다.

## 모바일 길이와 경계 재검토

첫 소개와 목록에 같은 분류가 반복되면 접근 가능한 분류 하나를 남긴다. 상세는 이미지 버튼 등 명확한 한 진입점으로 연결하고 관심 행동과 구분한다. 모바일에서는 설명/행동/이미지 높이의 누적도 측정한다.

## 첫 판단과 자료의 역할

상품의 소재·사용 상황과 실제 비교 항목을 연결하는 에셋을 우선한다. 첫 화면과 카탈로그가 같은 대상을 다른 근거로 보여주는지 확인하고, 사용 사진과 실물 상품의 사실성은 구분한다.

## 다음 판단으로 이어지는 근거

대표의 사용 장면과 목록의 상품 식별이 같은 사진 반복으로 끝나지 않게 한다. 실제 소재/규격/사용 근거가 없으면 확보 요청을 남기고 임의 혜택·성과를 만들지 않는다.
