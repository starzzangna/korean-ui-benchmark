# 콘텐츠로 구성을 결정하기

## 구성 선택

1. 방문자가 찾을 사실 세 가지와 핵심 행동 하나를 적는다. 메뉴 가격, 작업 역할, 서비스 결과물, 행사 날짜처럼 화면에서 검증 가능한 대상을 쓴다.
2. 사진·작업물·문서·일정의 실제 목록과 비율을 확인한다. 사진이 충분하면 크롭 전에 원본 구도를 보고, 참고 사진이면 실제 판매·운영 사진과 구분한다. 자료가 부족하면 누락 사실을 알리거나 텍스트·목록 중심으로 만든다. 임의 정물로 사실의 빈칸을 채우지 않는다.
3. 색상을 제외하고 서로 다른 구성을 두세 개 비교한다. 대표 콘텐츠, 탐색 방식, 섹션 순서 중 무엇이 달라지는지와 채택 이유를 DESIGN.md에 짧게 남긴다. 사용자가 방향을 지정했다면 이를 구체화하는 정도면 충분하다.
4. 대표 콘텐츠를 첫 화면의 주인공으로 둔다. 소개문과 CTA를 위해 콘텐츠를 불필요하게 아래로 미루지 않는다. 모바일에서도 동일한 정보 우선순위를 유지한다.

## 조건에 따른 선택 예시

| 조건 | 적합한 출발점 | 피해야 할 오해 |
|---|---|---|
| 식당, 음식 사진과 메뉴가 있음 | 음식 사진의 구도를 살린 넓은 면 + 가까운 메뉴·가격 | 참고 사진에 메뉴명을 붙여 실제 음식처럼 표시 |
| 포트폴리오, 작업 예시가 있음 | 작업 색인 또는 대표 사례부터, 소개는 짧게 | 거대한 자기소개와 별표가 작업 탐색을 밀어냄 |
| 전문 서비스, 실적 자료가 없음 | 요청 상황 → 제공 범위·결과물 → 문의 | 가짜 사례·고객 로고, 종이 콜라주로 신뢰를 대체 |
| 행사, 프로그램과 가격이 있음 | 일시·참가 조건 → 날짜별 시간표 → 신청 | 대형 워드마크가 날짜와 프로그램보다 먼저 읽힘 |
| SaaS 앱, 업무 데이터가 있음 | 작업 목록·검색·다음 행동 | 홍보용 히어로를 업무 화면에 삽입 |

이 표는 고정 템플릿이 아니다. 같은 업종도 사진·대상·과업이 달라지면 다른 구성이 적합하다.

## 장식 검토

별표·스티커·배지·회전 카드·그라데이션·큰 영문 워드마크를 발견하면 다음을 묻는다.

- 제공된 브랜드 근거가 있는가, 정보를 구별하거나 읽기 순서를 돕는가?
- 제거해도 정보와 인상이 같다면 어떤 역할을 하는가?
- 다른 카테고리에서도 같은 위치·형태로 반복되는가?

근거가 약하면 제거하거나 축소한다. 모든 장식을 금지하지 않으며, 의미 있는 행사 포스터·브랜드 요소는 유지할 수 있다. ‘의미 없는 장식 제거’라는 문구만 쓰지 말고 실제 제거·유지 항목과 이유를 기록한다.

## 고정할 품질과 선택할 표현

- 공통 계약: 입력 label, 키보드 초점, 오류 복구, 44px 목표 조작 영역, select 여유 공간, 아이콘 정렬, 읽기 대비.
- 프로젝트 선택: 색상, 타이포 역할, 콘텐츠 폭, 이미지 비율, 열 수, 모서리, 여백, 섹션 순서. 공통 계약이 동일한 카드나 파란 버튼을 요구하는 것은 아니다.
- 표면을 어둡게 또는 밝게 바꾸면 내부 제목·설명·링크·보조문구의 실제 전경/배경 조합을 다시 확인한다. 부모 배경만 바꿔 기존 흰 글자나 옅은 설명색이 남지 않게 한다. 열 수를 바꾸면 grid의 최소 콘텐츠 크기와 목업 자식의 고정 너비가 좁은 화면을 밀어내는지도 확인한다.

## 비교 방법

기능 성공, 정보 발견, 시각 선호를 별도로 평가한다. 같은 화면 크기·자료·과업을 사용하고 제작 조건을 가린 뒤 ‘가격 찾기’, ‘역할 이해하기’, ‘서비스 결과물 확인’, ‘일시와 참가비 찾기’를 수행한다. 소요 시간·정답 여부는 사람이 실제 수행한 경우에만 기록하고 자동 검사로 사람의 이해 시간을 추정하지 않는다.

선호와 이유는 과업 수행 후 받는다. 한 작성자의 사후 개선은 최초 제작 MD 효과의 증거로 합산하지 않는다. 표본·평가자·반복 수가 부족하면 미적 우위를 일반화하지 않는다.
