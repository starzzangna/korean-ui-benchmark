# 한국어 콘텐츠와 사진으로 인상을 만들기

## 한국형의 판단 기준

국내 사용자가 상품·매장·서비스를 파악하는 방식, 자연스러운 문구와 한글 조판, 방문·구매·예약 조건을 화면의 중심에 둔다. 특정 국가를 하나의 색·서체·레이아웃으로 고정하지 않는다.

- 제목은 제공하는 것을 말한다. ‘일상에 특별함을 더하다’만 쓰지 말고 실제 브랜드가 다루는 대상·활동을 함께 전달한다. 사용자가 준 슬로건은 존중하되 옆의 설명이 구체적인 내용을 맡는다.
- 한국어가 주언어라면 중요한 분류·조건·행동도 한국어로 읽힌다. 의미 없는 작은 영문 대문자 라벨로 위계를 대신하지 않는다. 영문 브랜드명·제품명은 실제 표기를 따른다.
- 제목·본문·가격/날짜·컨트롤은 서로 다른 역할이다. 모든 문구를 굵게 만들거나 모든 보조문구를 흐리게 하지 않는다. 한글은 실제 문장으로 줄바꿈을 검토하고 영문 display의 낮은 행간·과한 음수 자간을 그대로 복사하지 않는다.
- Pretendard는 한영 혼용 본문의 출발점이 될 수 있다. 서체만 바꿔 차별화했다고 보지 않는다. 실제 파일·굵기·제목 줄 수·읽기 폭은 [typography.md](typography.md)에서 결정한다. 명조는 문장 성격과 실물 브랜드에 맞을 때 선택한다.
- ‘프리미엄’, ‘고급’, ‘감성’ 요청은 시각 규칙으로 번역한다. 예: 사진에서 제품을 충분히 크게 보여주기, 제목과 가격의 안정적인 정렬, 제한된 글자 역할, 여유 있는 섹션 간격. 자동으로 검정/크림/금색·얇은 명조·큰 빈 공간을 선택하지 않는다.

## 사진 편집이 레이아웃의 일부다

1. **확보:** 실제 파일을 열어 대상·해상도·초점·사용 권한·참고 이미지 여부를 확인한다. 파일명이나 원격 URL만 보고 선정하지 않는다.
2. **역할:** 대표 사진은 장소/제품을 식별하고, 상세는 재료/결과를 설명하며, 보조 사진은 맥락을 더한다. 같은 사진을 크기만 바꿔 새로운 설명처럼 반복하지 않는다.
3. **연속성:** 한 시리즈에서 광원·색온도·촬영 거리가 충돌하는지 본다. 브랜드와 무관한 서로 다른 스톡 사진을 모아 실매장 기록처럼 만들지 않는다. 사진이 충분하지 않으면 페이지 길이를 줄이거나 정보 중심 방향을 선택한다.
4. **크롭:** 실제 이미지마다 데스크톱/모바일 `object-position`과 비율을 확인한다. 제품 전체·사람 얼굴·간판·작업 내용이 잘리면 비율을 바꾸거나 다른 사진을 사용한다. 모든 사진을 같은 16:9 카드로 자르지 않는다.
5. **연결:** 이름·가격·위치·작업 역할 등 식별 정보를 관련 사진 가까이에 둔다. 필요한 캡션은 제공한다. 접근 가능한 대체 텍스트와 보이는 설명의 역할을 구분한다. 사진 아래 설명을 일괄 금지하지 않는다.
6. **탐색:** 이미지가 핵심 상품·작업 정보라면 확대·상세·옵션 전환을 실제로 구현한다. 단순 hover 확대는 정보 탐색을 대신하지 않는다. 터치·키보드에서도 같은 내용에 도달한다.

외부/유료 사진 서비스와 이미지 생성은 필수가 아니다. 사실 자료가 없을 때 임의 풍경·CSS 정물·가짜 제품을 실제 브랜드의 증거로 채우지 않는다. 참고 이미지의 한계를 짧게 표시하고 필요한 자료가 무엇인지 결과에 남긴다.

## 색과 형태는 대상에서 결정한다

실제 사진·기존 패키지·공간·제품 UI 중 근거를 정하고 바탕/본문/강조/상태 역할을 배분한다. 사진의 지배적인 색을 모든 버튼에 그대로 쓰지는 않는다. 팔레트가 사진 식별과 텍스트 대비를 도와야 한다.

모서리·선·여백도 역할을 가진다. 제품 사진을 무조건 둥근 카드에 넣지 않고, 업무 목록을 의미 없이 떠 있는 패널로 분해하지 않는다. 일관된 읽기 축을 만들되 모든 섹션을 같은 3열 카드로 반복하지 않는다. 사진 중심 사이트에도 메뉴·가격·주소·일정 등 정보 영역의 밀도는 따로 설계한다.

시각적 특징은 한 가지 분명한 규칙에서 시작한다. 구체적인 작업물 크기 대비, 가격 열 정렬, 프로그램 시간 축처럼 콘텐츠와 관계있는 규칙을 고른다. 기본 조작의 예측 가능성은 유지하고 독창성을 위해 선택값·초점·CTA를 숨기지 않는다.
