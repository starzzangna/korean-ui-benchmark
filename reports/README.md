## 해석과 제한

한 작성자가 공통 엔진/템플릿과 자료를 사용했다. no skill도 작성자의 기존 지식/맥락 영향을 받는다. 원본 스킬의 모든 도구/gate를 통과한 무수정 패키지 비교가 아니다. 네트워크/서체/CDN의 차이도 남는다. 이 결과로 스킬만의 인과 효과·보편적 우위·실기기/다른 엔진/모든 접근성 상태를 인증하지 않는다. [비교 방법](../docs/METHOD.md)에 적용 범위를 공개했다.

정적 검사에는 링크·JS구문·28개 공통 데이터·에셋 해시·개인 경로/과거 실험 참조/비밀값 후보 검사를 포함한다. 이 검사는 보안 감사나 모든 결함 부재의 증명이 아니다. npm 설치 당시 취약점 보고0건이었으며 향후 상태를 보장하지 않는다.

재실행은 `npm run build`, `npm run check`, `npm test`, `npm run test:branches` 순서다. 현재 기록을 새로운 실행 결과로 갱신하려면 `artifacts/` 결과와 조건을 검토한 뒤 반영한다. CI는 결과를 실행 아티팩트로 보존하며 이 보고서를 자동 덮어쓰지 않는다.
